## Принятые решения
- **Закрытие заявки — только по кнопке**, не автоматически по истечению времени (R-75)
- **Старт мобилизации** фиксируется кнопкой «Мобилизация началась» на стороне FO (R-72)
- **Трёхшаговый флоу для Unwheeled техники**: Requestor → FO добавляет ТС → роль «Транспортировка» подтверждает → FO финально утверждает (R-20 обновлён)
- **Одна форма → несколько атомарных заявок**: система автоматически разбивает форму с несколькими единицами техники, связь через Work Order (R-19)
- **Нет буфера между бронями**: фиксированного минимального интервала нет; вопрос мобилизации — ответственность FO (R-02 закрыт)
- **Роль «Ответственный за транспортировку»**: отдельная роль в системе, к ней привязаны Heavy Ops (Ерлан) и команда Азбека (R-74)
- **Фактическое время** при закрытии: Requestor вводит факт. время начала и окончания работ для аналитики утилизации (R-71)
- **Приоритет внутренней техники** — бизнес-правило, технически не может быть принудительно реализован при текущей модели выбора техники
