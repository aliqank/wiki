## Принятые решения

- **Приоритет реализации макета** — только раздел «Типы техники» (полностью); остальные разделы — заглушки
- **Раздел «Типы техники»** охватывает работу с таблицами: EquipmentTypes, Properties, MeasurementUnits, PropertyEnumValues, EquipmentTypeProperties (EAV-схема)
- **Структура Admin Panel** (сайдбар): Типы техники (реализовать) | Флоты | Справочники | Доступ к Assigned технике | Системные параметры | Пользователи и роли | Аудит (все — заглушки)
- **Добавлено сверх исходного запроса пользователя:**
  - Поле «Класс техники» (HDE/HDV) в базовых параметрах — из BRD §5.1, FR-NEW-50
  - Поле «Work Center (JDE)» в базовых параметрах — из BRD §5.1 (каждый тип техники → один WC)
  - Флаги isFilterable и isVisibleInCard в таблице параметров (влияют на поиск и карточку)
  - Колонка «Единиц техники» в списке типов (блокировка удаления занятого типа)
  - Два режима добавления параметра: «Новый» / «Из справочника» (параметр переиспользуется между типами)
  - Drag & drop для sortOrder (порядок типов → порядок в UI Requestor)
  - Страницы-заглушки с описанием для каждого раздела сайдбара
- **Два таба в модалке добавления параметра:** «Новый параметр» (создаёт запись в Properties) / «Из справочника» (переиспользует существующий Properties)
- **Импорт параметров из другого типа** (M-AP-02): мультивыбор, уже добавленные параметры блокируются
