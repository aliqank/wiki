## Принятые решения

| Тема | Решение |
|------|---------|
| EquipmentTypes | Плоский список без иерархии (без parent-ссылки); requiresTransport — хранимое поле |
| Категории vs Fleet | Разные деревья: Equipment → equipmentTypeId + fleetId |
| ownershipType (Owned/LongTermRented/OnDemand) | На Equipments, не на Fleet — единая БД TCO + BP (BRD v8 §5.1) |
| EquipmentProperties.value | JSONB: `{"Bool": null, "Double": null, "Number": 50, "String": null}` |
| Number vs Double | Разделять: Number = integer (счётные), Double = decimal (измерения) |
| Статус техники | Динамический (не хранить); Frozen/InRepair — из отдельных таблиц; Decommissioned — isDecommissioned на Equipments |
| isActive | Убран — статус вычисляется из EquipmentFreezes и EquipmentRepairHistory |
| Фото | Отдельная таблица EquipmentPhotos (несколько фото на технику) |
| Трекеры | EquipmentTrackers с историей: assignedAt / removedAt |
| Заморозки | Отдельная таблица EquipmentFreezes (с историей, cancelledAt) |
| Ремонты | Отдельная таблица EquipmentRepairHistory (source: Manual/GDA) |
| Enum-значения свойств | Таблица PropertyEnumValues |
| Единицы измерения | Таблица MeasurementUnits (справочник) |
| ТО-партнёры | MaintenancePartners + EquipmentMaintenanceContracts (много партнёров на технику по разным направлениям) |
| Доступ к Assigned-технике | Через AAD-группу; отдельная таблица прав не нужна |
| Fleet Owner | 1 AAD-группа + FleetDelegations для делегирования конкретным пользователям |
| BP-пользователи | У BP нет AAD-групп, нужна своя запись в Users |
| Аудит-поля | Добавить в конце отдельным шагом |

## Дополнительный контекст

- Проектирование ведётся step-by-step: сначала Equipment, потом Bookings/Requests
- BRD актуальная версия — **v8** (файл `Результаты claude/2026-04-21 - HDV HDE BRD v8.md`), BRD "v9/v10" не существует
- "BRD 10 версии" в запросе пользователя = вероятно оговорка, имелась в виду последняя версия (v8)
- Unified database для TCO и BP техники подтверждена в BRD v8 §5.1 — одна таблица Equipments
- serviceZoneCode и costCenter — **разные понятия**: serviceZone = физическая зона (из PSWS), costCenter = финансовый ЦЗ (из JDE)
- EquipmentAssignedPermissions не создаём — доступ через AAD-группу
