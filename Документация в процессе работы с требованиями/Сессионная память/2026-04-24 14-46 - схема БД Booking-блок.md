## Принятые решения

| Решение | Детали |
|---------|--------|
| OQ-DB-1 закрыт | История изменений shareType — НЕ нужна; хранить только текущее значение |
| OQ-DB-2 отложен | Users.departmentCode — пропустить в этой итерации |
| OQ-DB-3 отложен | Аудит-поля (createdAt/updatedAt/createdBy на все таблицы) — добавим позже |
| OQ-DB-4 закрыт | RequestStatusHistory — добавить в эту итерацию (явная история нужна для аудита) |
| requestNumber | SERIAL UNIQUE (INT) в БД; форматируется в UI как REQ-YYYY-NNNNN; YYYY берётся из createdAt |
| closeComment | TEXT nullable на Booking — комментарий заявителя при закрытии брони |
| isDefaultWorkOrder | BOOLEAN DEFAULT FALSE на BookingRequests — для подразделений без JDE (FR-NEW-51) |
| Внешние ID | equipmentId, fleetId, userId — UUID без FK-ограничений (принцип из Equipment-блока v1) |
| Ручное закрытие | closedBy + closedAt на Booking; никаких автоматических переходов по времени |
| createdBy/createdAt на BookingRequests | Бизнесовые поля (не аудит) — включены в эту итерацию |
| Статус BookingRequests | Хранится явно (денормализация); агрегируется из Booking.status |

## Таблицы Booking-блока v1

### BookingRequests
`id` (UUID PK), `requestNumber` (SERIAL), `type` (Regular/ServiceWork), `status` (Draft/Submitted/InProgress/Completed/Cancelled), `workOrderJdeId` (nullable), `isDefaultWorkOrder` (BOOL), `location` (nullable), `workDescription`, `comments` (nullable), `priority` (P1–P4), `createdBy` (UUID ext), `createdAt`

### Booking
`id` (UUID PK), `requestId` (FK→BookingRequests), `equipmentId` (UUID ext), `fleetId` (UUID ext), `assignedFleetOwnerId` (UUID ext nullable), `status` (Draft/Submitted/Confirmed/Declined/Revoked/Terminated/InProgress/Closed), `startDt`, `endDt`, `mobilizationStartedAt` (nullable), `justification` (nullable), `declineReason` (nullable), `terminateReason` (nullable), `closedBy` (UUID ext nullable), `closedAt` (nullable), `closeComment` (nullable)

### BookingStatusHistory
`id` (UUID PK), `bookingId` (FK→Booking), `oldStatus` (nullable), `newStatus`, `changedBy` (UUID ext), `changedAt`, `comment` (nullable)

### RequestStatusHistory
`id` (UUID PK), `requestId` (FK→BookingRequests), `oldStatus` (nullable), `newStatus`, `changedBy` (UUID ext), `changedAt`, `comment` (nullable)
