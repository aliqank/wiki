## Принятые решения

### Work Center (OQ-NEW-G — закрыт)
- Work Center = тип работ (шаг в Work Order), **не атрибут техники**
- Один тип Equipment → работает только в **одном** Work Center
- Один Work Center → может обслуживаться **несколькими** типами Equipment
- Список кодов WC (15 штук): LRG, MGT, BHOE, DTRK, FTRK, GDRV, HYDR, OILT, VTRK, CDECK, CRANE, FORKL, GMLOG, MLIFT, MSINS — Асылбек скорректирует

### Карточка оборудования
- Убрать поле «Операционный статус»
- Добавить поля: **Заморозка** (флаг), **Причина заморозки**, **Дата завершения заморозки**
- Добавить поле **Принадлежность** (TCO Owned / Long term rented) — явно в карточке (раньше было только в глоссарии)
- Максимум полей выносить в справочники через Admin Panel (классы, категории, WC, локации, org-структура)

### Логистика (отличие от других подразделений)
- Логистика не работает в JDE и не имеет Work Center
- Поля WO и WC — **необязательные** для Логистики (не просто замена на Location, как было в FR-NEW-12)

### Страница «Подать заявку»
- Новый блок **«Выбрать Work Order из JDE»**: список WO из DataLake → выбор → автогенерация draft заявки → пользователь дозаполняет технику и время
- Это FR-NEW-48

### Поля WO из DataLake (расширены)
