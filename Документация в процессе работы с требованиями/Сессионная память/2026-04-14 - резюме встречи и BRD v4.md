## Принятые решения

### Карточка техники / Fleet
- Fleet может иметь **2+ Fleet Owner-а** (сменщики); оба отображаются в карточке + shared team email флота
- Уведомления через AD-группы: shared email + personal email участников группы
- Поддержка **нескольких трекеров** на одну единицу (один — моточасы, другой — GPS/пробег)
- Добавить в карточку: **плановые моточасы** и **плановый километраж в день** (редактирует FO; фактические — только из трекера)
- Добавить в карточку: **календарь бронирования** (FR-NEW-40) и **cost center**
- **Criticality** = требует сопровождения службы безопасности при перевозке (не приоритет ремонта)
- **Госномер** — не у всей техники; ТШО-номер — только при покупке; арендная техника приходит со своим госномером

### Специфические параметры по типам техники (новый раздел 5.1.1 BRD)
| Тип техники | Ключевые параметры |
|---|---|
| Погрузчик | Грузоподъёмность (до 2т / 2–4.5т / 4.5–8т), Тип (вилочный/ковшовый), Двигатель (эл/дизель) |
| Кранманипулятор | Грузоподъём техники, Грузоподъём крана, Длина стрелы, Длина кузова |
| Генератор | Мощность (выпадающий список: 30/60/80/100/120/130/200/250 кВт), Тип (колёсный/неколёсный/стационарный) |
| Компрессор моторный | Давление (атм), Производительность (м³/ч) |
| Самосвал | Тоннаж (основной), Тип кузова (вторичный, по фото) |
| Фрактанк | Без фильтров (все одинаковы); транспортировка — Kenworth Winch Truck (1 ед.) |
| Прицеп карго | Тип (низкорамный/стандартный), Тоннаж, Тип системы (пневм./стандарт) |
| Тягач HD | Без независимого фильтра — определяется типом прицепа; FO выбирает тягач |
