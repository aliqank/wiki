# UC-REQ-02.4 - Добавление техники в draft-заявку

**Created:** 2026-05-15  
**Last updated:** 2026-05-15  
**Автор документов:** Telman Nurzhanov (SA)

---

## Карточка use case

| Поле | Значение |
|---|---|
| Область действия | Модалка `Добавить технику` |
| Участник | `Requestor`, `ServiceWorkProcessor` |
| Покрываемые FR (BRD) | `FR-031`, `FR-038`, `FR-NEW-04`, `FR-NEW-08`, `FR-NEW-15`, `FR-NEW-71` |
| Покрываемые FR (Additional list) | — |
| Триггер | Пользователь выбрал одну или несколько единиц техники |
| Ожидаемый результат | В draft-заявку добавлены booking item-ы |
| Используемые API | `POST /booking-requests/{id}/items` |

---

## Основной сценарий

1. Пользователь выбирает одну или несколько единиц техники в результатах поиска.
2. Frontend вызывает `POST /booking-requests/{id}/items`.
3. Backend создаёт booking item-ы внутри draft-заявки.
4. Если для конкретного item требуется `justification`, item помечается как незавершённый до его заполнения.
5. Frontend отображает item-ы в составе draft-заявки.

---

## Альтернативные сценарии

1. Добавление item не прошло из-за недоступности техники.
   Backend возвращает ошибку валидации доступности.

2. Добавлены несколько item-ов.
   Каждый item создаётся как самостоятельная запись и обрабатывается отдельно.
