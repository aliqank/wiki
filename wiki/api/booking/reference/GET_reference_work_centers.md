## 1. Задачи, в рамках которых вносятся изменения в метод

Новый reference API для UC-2. Используется для загрузки фильтра `workCenter` в модалке выбора техники.

---

## 2. Функциональные требования

| Наименование проекта | Номер требования | Описание требования | Статус | Источник | Комментарий |
|---|---|---|---|---|---|
| TCO Booking Tool | FR-031 | Requestor can add/remove equipment items to a request | Confirmed | BRD v13 | Work center участвует в фильтрации техники |

---

## 3. Описание логики работы метода

1. Выбрать активные записи из `WorkCenters`.
2. Вернуть компактный справочник для фильтра поиска.
3. Сортировать записи по коду и отображаемому имени.

Сущности, участвующие в методе:
- читаются: [`WorkCenters`](../../../db/2026-05-21%20-%20DB%20Schema%20v12%20%28Azure%20SQL%2C%20Equipments%2C%20Booking%29.md#3-workcenters)
- изменения не выполняются

---

|---|---|
