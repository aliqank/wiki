# DELETE /maintenance-partners/:id

## Карточка метода

| Параметр | Значение |
|---|---|
| Описание | Выполнить soft delete партнера ТО |
| Доступ только авторизованным пользователям | `+` |
| Модуль системы | `Admin Panel` |
| Endpoint URL | `/api/admin/v1/maintenance-partners/:id` |
| Метод запроса | `DELETE` |
| Согласовано | |

---

## 1. Задачи, в рамках которых вносятся изменения в метод

Новый метод. Удаляет запись партнера ТО через soft delete. Если партнер используется активными контрактами ТО, удаление запрещено.

---

## 3. Описание логики работы метода

1. Найти запись в `MaintenancePartners` WHERE `id` = `:id` AND `isDeleted = false`. Если запись не найдена — вернуть `404 NOT_FOUND`.
2. Проверить наличие активных контрактов: COUNT(`EquipmentMaintenanceContracts` WHERE `partnerId` = `:id` AND `isDeleted = false`). Если count > 0 — вернуть `409 MAINTENANCE_PARTNER_IN_USE`.
3. Выполнить soft delete: установить `isDeleted = true`, `deletedAt`, `deletedBy`.
4. Вернуть HTTP 204 No Content.

Сущности, участвующие в методе:
- читаются: `MaintenancePartners`, `EquipmentMaintenanceContracts`
- изменяются: `MaintenancePartners` (soft delete)
- транзакционность: не требуется
