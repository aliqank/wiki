---

## 1. Задачи, в рамках которых вносятся изменения в метод

Новый метод. Удаляет единицу измерения из справочника через soft delete. Если она используется активными характеристиками, удаление запрещено.

## 3. Описание логики работы метода

1. Найти запись в `MeasurementUnits` WHERE `id` = `:id` AND `isDeleted = false`. Если запись не найдена — вернуть `404 NOT_FOUND`.
2. Проверить наличие активных характеристик: COUNT(`Properties` WHERE `unitId` = `:id` AND `isDeleted = false`). Если count > 0 — вернуть `409 MEASUREMENT_UNIT_IN_USE`.
3. Выполнить soft delete: установить `isDeleted = true`, `deletedAt`, `deletedBy`.
4. Вернуть HTTP 204 No Content.

Сущности, участвующие в методе:
- читаются: `MeasurementUnits`, `Properties`
- изменяются: `MeasurementUnits` (soft delete)
- транзакционность: не требуется
