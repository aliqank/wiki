# Контекст домена — TCO HDV/HDE Booking Tool

## Проект
**HDV/HDE Booking Tool** для клиента **TCO (Tengizchevroil)**.
Домен: бронирование тяжёлой техники и оборудования на нефтяном промысле.
Роль пользователя: **бизнес-аналитик / системный аналитик**.

## Среда
Enterprise-окружение TCO: **Azure AAD, JDE E1, DCT, PSWS, DOA, DataLake, GIS (MAPH/Atlas)**.

## Ключевые сущности
- **Equipment** — единица техники HDV/HDE (категории: Assigned / Shared / Shared with Conditions)
- **Fleet** — парк техники (внутренний TCO или внешний БП)
- **Request** — заявка на бронирование (один Requestor, несколько единиц техники)
- **Booking** — подтверждённое бронирование конкретной единицы

## Роли
| Роль | Описание |
|------|----------|
| Requestor | Подаёт заявки на технику |
| Fleet Owner (FO) | Управляет внутренним парком TCO, согласует заявки |
| CC Owner | Согласует заявки на внешний флот (БП) |
| Contract Specialist | Работает с контрактами БП |
| Admin | Настройка системы |

## Цепочки согласования
- **Внутренний флот (Cat 1/2):** Requestor → Fleet Owner → подтверждение/отказ
- **Внешний флот (Cat 3 / БП):** Requestor → CC Owner → Fleet Owner BP

## Бизнес-правила
- Приоритет внутреннего флота (TCO) перед внешним (БП)
- Таймауты Fleet Owner: 24–48 ч с эскалацией (настраивается в Admin Panel)
- Горизонт бронирования: 1 месяц, максимальная длительность: 1 неделя (настраивается)
- BP-флот — "витрина" (каталог), не broadcast-модель
- Assigned-техника видна всем Requestor-ам
