| D-70 | **Route tracking** (маршрут перемещения за период): отображение на карте по диапазону дат через GIS-интеграцию. **TBD** — решение флитоунеров к 20.04 | TBD | 📌 Ожидает решения |

## Экран 5a — Дашборд утилизации *(новое)*

> Источник: встреча 17.04. Отдельный экран/вкладка в разделе «Оборудование» (FO).

### Общая структура

| # | Требование | Приоритет | Статус |
|---|-----------|-----------|--------|
| D-55 | **3 таба** на дашборде утилизации: «Моточасы» \| «Километраж» \| «Комбайн» (максимальное из двух). Тип техники определяет, какие вкладки активны: HDE — только Моточасы; HDV — только Километраж; смешанный тип — все три | Must | ⚠️ Добавить |
| D-56 | **Источник данных:** утилизация берётся из **трекеров**, вне зависимости от наличия заявок в Booking Tool | Must | ⚠️ Зафиксировать |
| D-57 | **Целевое значение** (target): отдельная колонка с максимальным суточным нормативом, заданным FO для каждой единицы техники (например: 2 000 моточасов / 1 500 км). Отображается первой слева после названия/типа | Must | ⚠️ Добавить |
| D-58 | **Среднее за период**: добавить колонку со средним значением утилизации за выбранный диапазон (ремонтные дни исключаются). Таблица **сортируется по этой колонке** (от большего к меньшему) | Must | ⚠️ Добавить |

### Цветовая схема

| # | Требование | Приоритет | Статус |
|---|-----------|-----------|--------|
| D-59 | **Цветовой градиент** ячеек: 0% — красный → 50% — жёлтый → 100% — зелёный. Плавный переход, не дискретные ступени | Must | ⚠️ Добавить |

### Ремонтные дни

| # | Требование | Приоритет | Статус |
|---|-----------|-----------|--------|
| D-60 | Дни, когда техника была **на ремонте**, отображать **иконкой гаечного ключа** (или аналогичной) в ячейке вместо числового значения. Отдельный цвет для ремонта не нужен | Must | ⚠️ Добавить |
| D-61 | Данные о ремонте берутся из **JDE**: `commitment date` → начало ремонта, `planned date` → ожидаемое завершение, `completed date` → фактическое завершение | Must | ⚠️ Интеграция JDE |
| D-62 | Для **BP-техники** и техники вне JDE: ручной ввод ремонтных периодов FO-ем — **Phase 2**, не входит в текущий релиз | Phase 2 | 📌 Отложено |

### Навигация и фильтры

| # | Требование | Приоритет | Статус |
|---|-----------|-----------|--------|
| D-63 | **Переключение вида**: «По дням» (текущее, как в прототипе) / «По месяцам» (средняя по месяцу в каждой ячейке). Переключатель сверху | Should | ⚠️ Добавить |
| D-64 | **Фильтр «Принадлежность»** в левом сайдбаре дашборда: TCO Owned / Long-term rented | Must | ⚠️ Добавить |
| D-65 | **Сортировка по столбцу «Среднее»** — нажатие на заголовок сортирует список техники по среднему убыванию/возрастанию | Should | ⚠️ Добавить |

### Визуальное оформление

| # | Требование | Приоритет | Статус |
|---|-----------|-----------|--------|
| D-66 | **Убрать фотографии техники** с дашборда утилизации (увеличивают время загрузки). Вместо фото — **иконки по типу техники** (кран, погрузчик, самосвал, грузовик и т.д.). Дизайн-команда готовит примеры иконок для согласования с заказчиком | Must | ⚠️ Подготовить иконки |

| # | Требование | Приоритет | Статус |
