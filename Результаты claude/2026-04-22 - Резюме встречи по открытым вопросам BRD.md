## 3. Вопросы по интеграции данных

### 3.1 Частота обновления заявок из JDE E1

**Проблема:** DataLake-джобы по JDE запускаются один раз в сутки (~5:00 утра). Если обновление только раз в день — заявка, утверждённая в течение дня, попадёт в систему лишь на следующее утро.

**Предложение:** перейти от DataLake к интеграции по API с JDE E1 напрямую (зависит от возможности со стороны JDE)

### 3.2 Частота обновления показателей утилизации

**Решение:**
- Обновление **один раз в конце рабочего дня** (удовлетворяет требования Логистики)
- В мониторинге показывается утилизация **за предыдущий день**, Для логистики: это достаточно
- **Действие:** Уточнить позицию команды **maintenance** — возможно, им нужна более частая обновляемость

## 4. Обзор BRD v9 — ключевые решения

### Техника и флит
- **Long-term rented** техника: добавляется в систему как **внутренний флит**; Internal Fleet Owner управляет ею. Процесс заявки — идентичен внутреннему флиту.
- **Assigned-техника:** присутствует в базе данных, **не шерится**, но может быть забронирована с `justification`. Fleet Owner может отклонить такую заявку.
- **Поле sharing condition** (share / assigned / share with conditions): будет добавлено в Figma-макет карточки техники.

### Интеграции
| Интеграция | Статус |
|-----------|--------|
| JDE (JDE) — work orders | Актуальна; нужен более частый интервал через API |
| JDE — данные по ремонту техники | Добавлена в скоп |
| PSWS | Актуальна только в части **White Pages** |
| DOA (cost centers) | **Неактуальна** — cost centers исключены из процесса |

## 5. Карта / GIS

- Встреча с командой GIS - 23.04.2026;
- **Teltonika-трекеры:** передают геолокацию в реальном времени (в рабочем состоянии); при выключении — последняя известная точка
- **LoRaWAN (GPS-only):** 3 обновления в день (ограничение батарейки)
- **Дополнительные GPS-датчики:** запланированы для техники без телематики (Камаз и др.) — от батарейки, 3 раза в день
- **Утилизация на карте (tooltip):** команда Maintenance хочет видеть утилизацию за текущий день; требуется задать интервал обновления (предположительно: каждые 30 мин или 1 час)

## 6. Обсуждение cost centers (нерешённый момент)

Если long-term rented техника передаётся другому подразделению, нужно ли дополнительное согласование для перевыставления счёта?

**Требование, подтвержденное неоднократно ранее:** Fleet Owner, принявший технику в long-term, управляет ею на своё усмотрение внутри компании. Дополнительного согласования не требуется.

**Действие:** Обсудить этот момент на следующей BRD review с новой вахтой.
