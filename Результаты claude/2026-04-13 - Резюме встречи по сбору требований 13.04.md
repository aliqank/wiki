## 2. Демонстрация дизайна

### 2.1 Форма создания заявки
- Workorder, описание и комментарии вынесены в **левый сайдбар** (т.к. 1 заявка = 1 workorder)
- К одному workorder-у можно добавлять несколько единиц техники
- **Статус ремонта из JDE** (дата выхода, факт ремонта) будет отображаться серым под единицей техники — если JDE предоставит данные
- Поле «перевозная техника»: если требуется транспортировка самой техники — Fleet Owner добавляет её отдельной заявкой другому Fleet Owner-у

### 2.2 Список оборудования (Fleet Owner)
- Левый сайдбар: счётчики по статусам (в работе, на ремонте, свободные)
- Центральная часть: список техники по флотам
- **Добавить:** карту (временно убрана) рассмотреть позже

### 2.3 Карточка техники
Базовые поля карточки (подтверждены):
- Модель, фото, производитель, номер ТШО, ID (серийный номер), госномер
- Класс, статус использования, criticality, год выпуска
- **Tracker number** (возможна привязка нескольких трекеров)
- Комментарии реквестеров — в правом сайдбаре, сортировка по дате (свежие сверху)
- **Добавить:** календарь бронирования (какие периоды техника уже забронирована)
- **Добавить:** cost center
- **Добавить:** плановые моточасы и плановый километраж в день

## 3. Решения по карточке техники

### 3.1 Fleet Owners (сменщики)
- **Решение:** отображать двух владельцев флота + **общая (shared) почта**
- Мотивация: заявки и уведомления направляются на общий ящик; авторизация — через персональный e-mail
- **Нотификации:** через AD-группы (включают и shared, и персональный email)
- Вручную: администратор может менять состав владельцев при переводе в другой отдел

### 3.2 Несколько трекеров на технике
- Возможна привязка нескольких трекеров: один — для моточасов, другой — GPS/пробег
- **Решение:** поддержать несколько трекеров в карточке

### 3.3 Поле Criticality
- Означает «критичное оборудование» = при перевозке требует сопровождения службы безопасности
- **Вывод:** поле оставить, пояснить смысл в интерфейсе

### 3.4 Утилизация
- По некоторой технике — только моточасы, по другой — только пробег (км/день), по некоторой — оба параметра
- **Добавить поля:** плановые моточасы + плановый километраж в день
- Текущие (фактические) значения — обновляются системой, не редактируются вручную

### 3.5 Госномер и ТШО-номер
- Не у всей техники есть госномер (у некоторой стационарной — нет)
- ТШО-номер присваивается только при покупке для ТШО; арендная техника приходит со своим госномером
- Техника business-партнёров (L-rent) — может не иметь ни того, ни другого

## 4. Специфические параметры по типам техники

### 4.1 Погрузчик (Loader)
| Параметр | Значения |
|---|---|
| Грузоподъёмность | 200 кг – 2 т / 2 т – 4,5 т / 4,5 т – 8 т (диапазон, указан клиентом) |
| Тип | Вилочный / Ковшовый |
| Тип двигателя | Электрический / Дизельный |

### 4.2 Кранманипулятор (Crane-manipulator)
| Параметр | Примечание |
|---|---|
| Грузоподъёмность техники | Сколько поднимает сам автомобиль |
| Грузоподъёмность крана | Отдельный параметр |
| Длина стрелы | Вылет стрелы |
| Длина кузова | Под размер груза |

### 4.3 Генератор передвижной (Mobile Generator)
| Параметр | Значения / формат |
|---|---|
| Мощность (кВт) | Выпадающий список: ~30, 60, 80, 100, 120, 130, 200, 250 кВт |
| Напряжение | — |
| Ток | — |
| Ёмкость батареи | — |
| Тип | Колёсный / Неколёсный / Стационарный |

> **Асылбек** подготовит разбивку по мощностям генераторов и компрессоров к следующей встрече.

### 4.4 Компрессор моторный (Motor Compressor)
| Параметр | Примечание |
|---|---|
| Давление (атм) | Основной фильтр |
| Производительность (м³/ч) | Второй фильтр |

> Разбивка по категориям — аналогично генераторам, Асылбек подготовит.

### 4.5 Самосвал (Dump Truck)
| Параметр | Примечание |
|---|---|
| Грузоподъёмность (т) | Основной фильтр |
| Тип кузова (открытый/закрытый) | Вторичный; пользователь ориентируется по фото |

### 4.6 Фрактанк (Frac Tank)
- Все фрактанки одного объёма → фильтры не нужны, выбираем любой
- Для перевозки фрактанка — единственная машина: **Kenworth Winch Truck** (1 единица)
- Если занята → фрактанк стоит; решение по замене пока не предусмотрено

### 4.7 Прицеп грузовой / Трейлер карго (Cargo Trailer)
| Параметр | Значения |
|---|---|
| Тип | Низкорамный / Стандартный |
| Грузоподъёмность (т) | — |
| Тип системы | Пневматическая / Стандартная |

### 4.8 Тягач (Semi-truck / HD Truck)
- Тягач определяется **типом прицепа** → в карточке заявки
- Тип прицепного устройства — как возможный атрибут

> **Вакуум-траки и другие типы техники** не разобраны — Асылбек проработает оставшиеся типы по master fleet таблице.

## 6. Разбор BRD (остановились на разделе 6.1–6.3)

### 6.1 User & Role Management
| Требование | Статус |
|---|---|
| RBAC | Подтверждено |
| External Fleet Management (FR002) | Перенесено в DCT (deprecated в системе) |
| Service Work Processor | Роль открытая; предположительно — графисты, обрабатывающие черновики из JDE |
| Cost Center Owners | **Не нужны** для internal/long-term флоу (нет шага подтверждения от CC) |
| Делегирование Fleet Owner → любой сотрудник ТШО | Требует согласования с отделом кибербезопасности |
| Временные параметры (таймауты, эскалации, reminders) | Настраиваются в Admin Panel |

### 6.2 Admin функционал
- Создание / редактирование / удаление флотов (internal и external)
- Назначение/смена Fleet Owner-ов
- Привязка флота к AD-группам (для управления доступом)
- Управление equipment templates и request templates
- Доступ к dashboards и отчётам

### 6.3 Equipment Management
- Internal Fleet Owner может редактировать парки (обновлено 10.04)
- Флотам присваивается имя/идентификатор → решает проблему текучки кадров среди владельцев
- Отзыв комментариев к технике — отображаются в карточке (правый сайдбар)
- Стационарная техника исключается из выборки (assign = не букируется)
- Assign-техника: доступна всем, но бронируется только с justification (обоснованием)

### 6.4 Shared with / without Conditions — прояснение
| Тип | Смысл |
|---|---|
| Shared without conditions | Общедоступна, бронируется без ограничений |
| Shared with conditions | Требует **обоснования (justification)** при бронировании (специфичная техника, e.g. компрессор для закачки баллонов, химтрак) |

> **Вывод:** два типа отличаются ТОЛЬКО наличием поля justification. Fleet Owner в любом случае может отозвать бронь в любой момент — это отдельный механизм.  
> BRD обновить: добавить пояснение к каждому типу.
