## Глоссарий терминов — HDV/HDE классификация

### По мобильности и функциям

| Категория | Определение РУ | Примеры |
|-----------|----------------|---------|
| **Self-propelled motorized (HDV/HDE)** | Оборудование с собственным двигателем, способное передвигаться самостоятельно | Бульдозеры, самосвалы, автогрейдеры, тракторы, крановые установки на колёсном ходу |
| **Not self-propelled motorized HDE** | Оборудование с двигателем для рабочих функций, но без самостоятельного передвижения. Требует буксировки или транспортировки | Компрессоры на прицепе, передвижные генераторы, гидравлические насосы, осветительные мачты |
| **Stationary HDE** | Стационарно установленное оборудование, предназначенное для работы в одном месте | Стационарные генераторы, промышленные котлы, насосы без перемещения |
| **Non-motorized HDE** | Оборудование без двигателя, работающее от внешнего источника энергии или вручную | Прицепы, ручной инструмент, контейнеры без электропитания |

**Примечание:** *Unwheeled техника* = техника, требующая **техники для перемещения** для доставки на объект = Not self-propelled motorized HDE + Non-motorized HDE. Stationary HDE — исключение (не перемещается).

### По статусу использования

| Статус | Определение РУ |
|--------|----------------|
| **Shared without conditions** | Техника может быть передана пользователям без условий |
| **Shared with conditions** | Техника может быть передана, но FO может перераспределить её под более высокоприоритетные заявки |
| **Assigned** | Техника закреплена за одним подразделением/локацией. Доступна ограниченному кругу пользователей. Обоснование обязательно |

### По владению (ownership type)

| Тип | Определение | Режим бронирования |
|-----|-------------|-------------------|
| **Owned (TCO)** | Собственная техника ТШО | Полное бронирование через систему |
| **Long-term rented** | Долгосрочная аренда у BP; техника де-факто в управлении ТШО | Полное бронирование через систему (как Owned) |
| **On-demand rented** | Техника BP, арендуется по запросу | Phase 1: только витрина; бронирование — вне системы |
