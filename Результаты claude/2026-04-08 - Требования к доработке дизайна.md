## Экран 2 — Модальное окно выбора техники (Requestor)

| # | Замечание | Приоритет | Статус |
|---|-----------|-----------|--------|
| D-03 | **Убрать фильтр по мобильности** (Self-propelled motorized, Not self-propelled и т.д.) из интерфейса Requestor-а — непонятная терминология для рядового пользователя | Must | ⚠️ Доработать |
| D-04 | Показывать **плоский список типов техники** (погрузчики, компрессоры, генераторы, краны и т.д.) без разделения по мобильности | Must | ⚠️ Доработать |
| D-05 | **Не отображать стационарное оборудование** у рядового Requestor-а. При этом Requestor-ы которые имеют роль Fleet owner-а могут иметь возможность подать заявку на бронь | Must | ⚠️ Доработать |
| D-06 | Фильтры в правой части модала — **динамические по типу техники**: для каждого типа показывать только релевантные параметры (погрузчик → грузоподъёмность + тип ковша; компрессор → мощность/давление; генератор → мощность/кВт) | Must | ⚠️ Доработать |
| D-07 | В таблице результатов поиска добавить колонки: **TCO-номер** (equipment number) + **госномер** (государственный регистрационный номер) | Must | ⚠️ Доработать |
| D-08 | Поиск по названию/госномеру/модели (кнопка в правом верхнем углу) — сохранить | Should | ✅ Одобрено |
| D-09 | При **наведении на строку** техники в результатах — показывать **всплывающее фото оборудования** (tooltip с изображением) | Should | ⚠️ Добавить |
| D-10 | В строке результата отображать: модель, марка, TCO-номер, госномер | Must | ⚠️ Доработать |
| D-11 | Техника на ремонте — отображать **серым**, **недоступна для выбора**, но видима; показывать подпись «На ремонте до [дата]» | Should | ⚠️ Добавить |

## Экран 3 — Форма создания заявки (Requestor)

| # | Замечание | Приоритет | Статус |
|---|-----------|-----------|--------|
| D-12 | Поле **Work Order** — числовой ввод (7-значное число), **обязательное** для Maintenance / Railroad / Operations флотов | Must | ⚠️ Доработать |
| D-13 | Поле **Location** — добавить для SCM Logistics: текстовый ввод; описание: куда нужна техника | Must | ⚠️ Добавить |
| D-14 | **Динамическое поведение полей**: если Requestor выбирает технику из флота SCM Logistics → поле Work Order неактивно, поле Location активно. Для всех остальных флотов → Work Order обязательно | Must | ⚠️ Добавить |
| D-15 | Поле **Описание работ** — **обязательное**, ограничение ~50 символов | Must | ⚠️ Доработать |
| D-16 | Поле **Комментарии** — **опциональное**, без жёсткого лимита символов | Should | ⚠️ Добавить |
| D-17 | При выборе Unwheeled техники (Not self-propelled / Non-motorized) — уведомление «Для перемещения данной техники будет добавлена техника-перевозчик» | Should | ✅ Из R-43 |
| D-18 | Кнопки формы: Сохранить черновик / Отправить / Отмена | Must | ✅ Одобрено |

## Матрица «тип техники → фильтры поиска» (заполнить совместно с TCO)

| Кран | Грузоподъёмность, тип | ⚠️ Уточнить |

| Трактор / Бульдозер | Мощность, тип навесного | ⚠️ Уточнить |
