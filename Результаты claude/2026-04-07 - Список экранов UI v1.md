# Список экранов и модальных окон — Booking Tool UI v1
**Дата:** 2026-04-07
**Тип документа:** Реестр экранов для дизайн-макетов
**Scope:** Phase 1 — роли Requestor и Fleet Owner (Internal)
**Целевая аудитория:** Стейкхолдеры TCO (первичная демонстрация)

---

## Навигация по ролям

| Роль | Экраны | Модальные окна |
|------|--------|----------------|
| **Requestor** | R-01 … R-06 (6 экранов) | M-R1, M-R2 (2 модала) |
| **Fleet Owner** | FO-01 … FO-06 (6 экранов) | M-FO1, M-FO2, M-FO3 (3 модала) |
| **Итого** | **12 экранов** | **5 модальных окон** |

---

## РОЛЬ: REQUESTOR

### R-01 — Dashboard (Главная)

**Назначение:** Первый экран при входе. Даёт быстрый обзор активности пользователя и требующих внимания событий.

**Ключевые элементы:**
- Хедер: логотип + имя пользователя + его роль (Requestor) + иконка уведомлений (badge с числом)
- Боковая навигация: Главная · Каталог техники · Мои заявки
- **Счётчики-карточки (4 шт.):**
  - Активных заявок (в работе или ожидают ответа FO)
  - Ожидают вашего действия (FO отказал → нужно выбрать другую технику)
  - Завершены за последние 30 дней
  - Отклонены / отменены
- **Секция "Требуют внимания":** список заявок, по которым FO отказал — нужно выбрать другую технику (статус «Вернулась на выбор»). Кнопка «Выбрать технику»
- **Секция "Активные заявки":** последние 5 активных бронирований с кратким статусом и прогресс-индикатором

**Требования:** R-02, R-56, R-57

---

### R-02 — Каталог техники (Поиск и выбор)

**Назначение:** Requestor ищет и выбирает конкретную единицу техники перед созданием заявки. Ключевой экран (targeted-модель, R-55).

**Ключевые элементы:**
- **Панель фильтров (левый сайдбар или верхняя строка):**
  - Тип техники (dropdown): погрузчик / компрессор / генератор / кран / …
  - Дата и время начала — дата и время окончания (date-time picker)
  - Технические характеристики (динамически по типу):
    - Погрузчик: грузоподъёмность (range slider: 2–4 т / 4–8 т)
    - Компрессор: давление bar (мин), объём подачи (мин)
    - Генератор: мощность кВт (мин)
  - Кнопка «Найти»
- **Список результатов (карточки техники):**
  - Каждая карточка: тип · название/модель · Fleet Owner · ключевые характеристики · статус (Shared / Shared with Conditions + цветовой маркер) · подвижная/стационарная (иконка трала если стационарная)
  - Если стационарная — предупреждение: «К этому оборудованию будет добавлен трал»
  - Кнопка «Выбрать» на каждой карточке
- **Пустое состояние:** «Техника по вашим параметрам недоступна в указанный период. Попробуйте изменить дату или параметры.»

**Требования:** R-55, R-61, R-12, R-13, R-14, R-43, R-02

**Примечание:** Assigned-техника в результатах не отображается (R-13).

---

### R-03 — Подача заявки (Create Request)

**Назначение:** Форма создания заявки после выбора техники в каталоге. Техника уже предзаполнена.

**Ключевые элементы:**
- **Выбранная техника** (сверху, read-only блок): тип · модель · Fleet Owner · характеристики · период (перенесён из каталога). Кнопка «Изменить» (возврат в каталог)
- **Блок — Если стационарная техника:**
  - Жёлтый баннер: «К заявке будет автоматически добавлен трал. Fleet Owner назначит транспорт после подтверждения.»
- **Обязательные поля:**
  - JDE / GDE Work Order № (text input с пояснением: «Используется FO для определения точки доставки»)
  - Приоритет: P1 / P2 / P3 / P4 (radio или dropdown с описанием каждого уровня)
  - Описание работ (textarea, необязательное)
- **Кнопки:** «Подать заявку» (primary) · «Назад в каталог» (secondary)
- После подачи — Success-уведомление: «Заявка #XXXX создана. Ожидайте ответа Fleet Owner.»

**Требования:** R-01, R-15, R-16, R-28, R-43, R-62, R-03, R-04

---

### R-04 — Список моих заявок (My Requests)

**Назначение:** Полный список заявок пользователя с фильтрацией и быстрыми действиями.

**Ключевые элементы:**
- **Фильтры:** по статусу (все / активные / ожидают FO / в работе / завершены / отклонены) · по дате · по приоритету
- **Таблица / список заявок** — каждая строка:
  - №  заявки · тип техники · Fleet Owner · период · приоритет (цветовой чип P1/P2/P3/P4) · **статус** (цветовые бейджи) · дата создания · иконка действий
- **Статусы заявки:**
  - 🔵 Draft — черновик
  - 🟡 Pending FO — ожидает ответа FO (с таймером тайм-аута)
  - 🟠 Action Required — FO отказал, нужно выбрать другую технику
  - 🟢 Confirmed — FO подтвердил
  - 🟢 In Progress — бронирование активно (техника на объекте)
  - ✅ Completed — завершено
  - 🔴 Rejected — отклонено
  - ⛔ Cancelled — отозвано
- **Быстрые действия** (из строки): Просмотр → Детали заявки

**Требования:** R-10, R-15, R-23, R-57, R-58

---

### R-05 — Детали заявки — Requestor (Request Detail)

**Назначение:** Полный просмотр заявки: статус, назначенная техника, таймлайн событий. Отправная точка для всех действий.

**Ключевые элементы:**
- **Шапка заявки:** №, статус (бейдж), приоритет, дата создания
- **Блок — Техника:** тип · модель · Fleet Owner · характеристики · период · статус брони
- **Блок — Параметры:** Work Order · описание работ · Cost Center (если внешний флот)
- **Блок — Таймлайн событий** (вертикальная лента):
  - Создана · Отправлена FO · Подтверждена/Отклонена · В работе · Завершена
- **Кнопки действий (контекстные — появляются по статусу):**
  - При статусе Draft/Pending: «Редактировать» · «Отозвать заявку»
  - При статусе Confirmed/In Progress: «Завершить» (→ M-R1) · «Запросить продление» (→ M-R2)
  - При статусе Action Required: «Выбрать другую технику» (→ R-02, каталог)

**Требования:** R-10, R-46, R-57, R-58, R-56

---

### R-06 — Редактирование заявки (Edit Request)

**Назначение:** Изменение параметров заявки, доступно пока статус Draft или Pending FO.

**Ключевые элементы:**
- Форма идентична R-03, но с заполненными данными
- Блок выбранной техники: кнопка «Заменить» (переход в каталог)
- Поля: Work Order · приоритет · описание работ · даты
- **Предупреждение** (если статус Pending): «Внимание: FO уже получил уведомление. Изменение заявки отправит ему обновлённую версию.»
- Кнопки: «Сохранить изменения» · «Отмена»

**Требования:** R-28, R-62, R-15, R-16

## РОЛЬ: FLEET OWNER

### FO-01 — Dashboard (Главная FO)

**Назначение:** Первый экран для FO при входе. Акцент на ожидающих действиях и своём парке.

**Ключевые элементы:**
- Хедер: имя + роль (Fleet Owner) + наименование своего парка + иконка уведомлений
- Боковая навигация: Главная · Входящие заявки · Мой парк
- **Счётчики-карточки:**
  - Новых заявок (ожидают ответа) + индикатор срочности (таймер тайм-аута)
  - Активных бронирований (техника сейчас в работе)
  - Запросов на продление (ожидают ответа FO)
  - Единиц в парке (всего / доступных / занятых / на ТО)
- **Секция "Требуют ответа":** входящие запросы с таймером — сколько осталось до эскалации. Кнопка «Ответить»
- **Секция "Активные брони":** техника сейчас в работе с датой окончания

**Требования:** R-23, R-24, R-57, R-58

---

### FO-02 — Входящие заявки (Incoming Requests)

**Назначение:** Список всех запросов, адресованных FO. Рабочий экран FO.

**Ключевые элементы:**
- **Фильтры:** статус (новые / подтверждённые / в работе / завершённые) · приоритет · дата
- **Список заявок** — каждая строка:
  - Requestor (ФИО + отдел) · тип техники (конкретная единица) · период · приоритет · статус · ⏱ оставшееся время на ответ (для Pending-статусов) · иконка трала (если стационарная техника) · кнопка «Детали»
- **Визуальный акцент на срочность:** P1 + истекающий тайм-аут → красная строка

**Требования:** R-23, R-24, R-33, R-60

---

### FO-03 — Детали заявки — FO (Request Detail for FO)

**Назначение:** Полный просмотр входящей заявки для принятия решения. Отправная точка для Принять / Отклонить / Назначить транспорт.

**Ключевые элементы:**
- **Шапка:** № · приоритет · таймер (осталось X часов на ответ) · статус
- **Блок — Запрошенная техника:** единица из своего парка (тип · модель · характеристики) + статус доступности в запрошенный период
- **Блок — Параметры заявки:** Requestor · Work Order · описание работ · период
- **Блок — Транспорт** (если стационарная техника):
  - Статус: «Транспорт не назначен» / «Назначен: трал №XXX»
  - Кнопка «Назначить транспорт» (→ M-FO3)
- **Кнопки действий:**
  - При статусе Pending: «Принять заявку» (primary, зелёная) · «Отклонить» (secondary, → M-FO1)
  - При статусе Confirmed/In Progress: «Изменить технику» (→ FO-04) · «Завершить бронирование» (→ подтверждение)
  - При наличии запроса на продление: баннер «Запрос на продление на X часов» + «Одобрить» / «Отклонить» (→ M-FO2)
- **Таймлайн событий** (история)

**Требования:** R-33, R-56, R-57, R-58, R-60, R-23

---

### FO-04 — Назначение / Замена техники (Assign / Change Equipment)

**Назначение:** FO выбирает или меняет конкретную единицу техники в подтверждённой заявке (если запрошенная вышла из строя и FO предлагает замену).

**Ключевые элементы:**
- **Контекст заявки** (вверху, read-only): Requestor · период · Work Order · характеристики из запроса
- **Список доступных единиц из своего парка** (отфильтрован автоматически по типу и периоду):
  - Каждая карточка: модель · характеристики · статус (✅ Свободна / ⚠️ Занята до XX.XX) · кнопка «Назначить»
- Если нужная техника занята — показываем это явно, не скрываем
- Кнопки: «Назначить выбранную» · «Отмена»
- После назначения — Requestor получает уведомление об изменении

**Требования:** R-27, R-56

---

### FO-05 — Мой парк (My Fleet)

**Назначение:** Просмотр всего парка техники FO с статусами и фильтрацией.

**Ключевые элементы:**
- **Фильтры:** тип техники · статус (доступна / занята / на ТО / заморожена) · подвижная/стационарная
- **Список единиц техники** (таблица или карточки):
  - Каждая запись: тип · модель · S/N · статус · share-тип (Shared / SWC / Assigned) + цветовой маркер · текущая бронь (если занята) · иконки действий
- **Кнопка «Добавить технику»** (→ FO-06, форма добавления)
- **Быстрые действия из строки:** Редактировать · Заморозить · Удалить

**Требования:** R-12, R-14, R-05, R-32, R-61

---

### FO-06 — Карточка техники (Add / Edit Equipment)

**Назначение:** Форма добавления новой или редактирования существующей единицы в парк FO.

**Ключевые элементы:**
- **Основные данные:**
  - Тип техники (dropdown)
  - Производитель / Модель
  - Серийный номер · Госномер (если применимо)
  - Подвижная / Стационарная (radio)
- **Технические характеристики** (поля динамически по типу):
  - Погрузчик: грузоподъёмность (т)
  - Компрессор: давление (bar) + объём (м³/мин)
  - Генератор: мощность (кВт)
- **Настройки доступности:**
  - Share-тип: Assigned / Shared / Shared with Conditions (radio + описание)
  - Статус: Active / Frozen (для КАП-ремонта)
- **Категория:** Cat 1 (TCO) / Cat 2 (BP в контракте)
- **Кнопки:** «Сохранить» · «Отмена» + «Удалить» (только для редактирования, с подтверждением)

**Требования:** R-12, R-05, R-31, R-32, R-61

## МОДАЛЬНЫЕ ОКНА

### M-R1 — Завершение бронирования (Requestor)

**Триггер:** Кнопка «Завершить» на экране R-05 (Детали заявки), статус In Progress.

**Содержимое:**
- Заголовок: «Завершить бронирование?»
- Краткая инфо: единица техники · период · Work Order
- Предупреждение: «После завершения техника будет помечена как доступная.»
- Кнопки: «Подтвердить завершение» (primary) · «Отмена»

**Требования:** R-57

---

### M-R2 — Запрос на продление (Requestor)

**Триггер:** Кнопка «Запросить продление» на экране R-05, статус Confirmed/In Progress.

**Содержимое:**
- Заголовок: «Запрос на продление бронирования»
- Текущий период (read-only)
- Поле: Новая дата/время окончания (date-time picker)
- Поле: Причина/комментарий (необязательно)
- Предупреждение (если есть следующая бронь у FO): «У данной единицы техники следующее бронирование с XX:XX. FO примет решение с учётом этого.»
- Кнопки: «Отправить запрос» · «Отмена»

**Требования:** R-58

---

### M-FO1 — Отклонить заявку (Fleet Owner)

**Триггер:** Кнопка «Отклонить» на экране FO-03 (Детали заявки FO).

**Содержимое:**
- Заголовок: «Отклонить заявку?»
- Краткая инфо: Requestor · техника · период
- **Обязательное поле:** Причина отказа (textarea, не может быть пустым). Подсказки-чипсы: «Техника занята» / «На ТО» / «Не в наличии» / «Другое»
- Кнопки: «Подтвердить отказ» (disabled если причина не заполнена) · «Отмена»
- После отказа — Requestor получает уведомление + заявка возвращается в статус «Action Required»

**Требования:** R-33, R-56

---

### M-FO2 — Ответ на запрос продления (Fleet Owner)

**Триггер:** Появляется как баннер+кнопки на FO-03 при наличии входящего запроса на продление.

**Содержимое:**
- Заголовок: «Запрос на продление»
- Requestor просит продлить до: [новая дата]
- Текущая бронь: [даты]
- ⚠️ Если следующая бронь: «Следующее бронирование этой техники: [имя Requestor, дата]»
- Кнопки: «Одобрить продление» (primary) · «Отклонить» (secondary, с необязательным комментарием)

**Требования:** R-58

---

### M-FO3 — Назначить транспорт / трал (Fleet Owner)

**Триггер:** Кнопка «Назначить транспорт» на FO-03, если в заявке стационарная техника.

**Содержимое:**
- Заголовок: «Назначить транспорт для доставки»
- Стационарная техника в заявке (read-only): тип · кол-во единиц
- **Выбор вида транспорта:** Трал / Бумтрак / Малый грузовик (radio)
- Поле: Кол-во единиц транспорта
- Поле: Номер/идентификатор транспорта (опционально)
- Кнопки: «Назначить» · «Отмена»

**Требования:** R-60, R-43
