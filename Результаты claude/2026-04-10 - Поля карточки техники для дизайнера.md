# Поля карточки техники — структура по типам для дизайна макетов
**Дата:** 2026-04-10  
**Тип документа:** Спецификация UI — поля карточки техники с примерами данных  
**Кому:** Дизайнер — для разработки макетов карточки техники  
**Источники:** FINAL Master Fleet File, встречи 03.04–10.04.2026, матрица фильтров (09.04)

---

## Контекст использования карточек

Карточка техники появляется в **двух контекстах**:

| Контекст | Кто видит | Цель | Объём полей |
|----------|-----------|------|-------------|
| **Модальное окно выбора техники** (при создании заявки) | Requestor | Выбрать подходящую технику | Минимальный — только ключевые параметры |
| **Раздел «Оборудование» FO** | Fleet Owner | Управление, редактирование, отчётность | Полный набор полей |

> Принцип: интерфейс Requestor-а — минималистичный. Интерфейс FO — полный.

---

## Часть 1 — Общие поля (блок A)

Отображаются для **всех типов техники** в карточке FO.  
Специфические параметры (грузоподъёмность, давление и т.д.) — см. Часть 2.

| # | Поле | Тип значения | Обяз. | Пример |

| A-04 | **Класс** | HDV / HDE | ✅ | HDV |
| A-05 | **Тип техники** (Category) | Справочник | ✅ | Lifting equipment motorized |
| A-06 | **HDV/HDE классификация** | Справочник | ✅ | Wheeled / Not SP motorized |
| A-07 | **Статус использования** | Assigned / Shared / Shared with Conditions | ✅ | Shared |
| A-08 | **Операционный статус** | Active / Reserved / Sent to BP | ✅ | Active |
| A-09 | **Criticality** | Low / High / Critical | ✅ | High |
| A-10 | **Производитель** | Строка | ✅ | Manitou |
| A-11 | **Модель** | Строка | ✅ | MHT 10120 |

| A-13 | **Серийный номер** | Строка | ✅ | MHT10120-21-00045 |
| A-14 | **VIN / Chassis No** | Строка | HDV | JKL1234567890 |
| A-15 | **Location** (базовое расположение) | Строка | ✅ | Wellpad T-12 |
| A-16 | **Service Zone** | Строка | ✅ | Zone B |

## Часть 3 — Макет строки в результатах поиска (общий шаблон)

Для **всех типов** строка в результатах поиска содержит:

```
┌────────────┬───────────────────┬──────────────┬────────────┬──────────────────────┬──────────────────┐
│  [Фото]    │  Модель           │  ТШО-номер   │  Госномер  │  Ключ. параметр(ы)   │  Статус          │
├────────────┼───────────────────┼──────────────┼────────────┼──────────────────────┼──────────────────┤
│ tooltip    │ Manitou MHT 10120 │ ТШО-04512    │ 025 KAE 14 │ Грузопод.: 3 т       │ ✅ Доступна      │
│ при наведении│                 │              │            │                      │                  │
├────────────┼───────────────────┼──────────────┼────────────┼──────────────────────┼──────────────────┤
│            │ Cummins C110D5    │ ТШО-02841    │    —       │ Мощность: 100 кВА    │ ✅ Доступна      │
├────────────┼───────────────────┼──────────────┼────────────┼──────────────────────┼──────────────────┤
│            │ Atlas Copco XRHS  │ ТШО-03157    │    —       │ 1600 CFM             │ 🔴 На ремонте   │
│            │                   │              │            │                      │    до 20.04      │
└────────────┴───────────────────┴──────────────┴────────────┴──────────────────────┴──────────────────┘
```

> **Правила:**
> - Ключевой параметр — **один–два главных** для данного типа техники (грузоподъёмность / мощность / объём / давление)
> - Техника на ремонте: строка серая, кнопка выбора неактивна, статус красным
> - При наведении на строку — **tooltip с фото** оборудования (D-09)
