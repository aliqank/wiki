### 2.4 Примечания по реализации

1. **Блок B — условное отображение:** технические поля из Блока B показываются в карточке только если значение заполнено в БД. Пустые поля не отображаются.

2. **Статус ремонта (A-21):** источник — JDE (SQL). Если оборудование в ремонте → подсветить красным и показать «В ремонте до [дата]». Иначе — «Доступна».

3. **Стоимость капитала (C-09):** показывать только пользователям с ролью Admin или FO.

4. **Фото (A-23):** загружается FO из интерфейса «Оборудование» (D-28). Показывается как tooltip при наведении в поиске Requestor-а (D-09).

5. **Assigned поля (A-18, A-19):** видимы для FO всегда. Для Requestor-а — только если у него есть доступ к бронированию Assigned техники (R-54).

6. **Deprecated типы:** для единиц техники с deprecated-категорией предусмотреть режим «только просмотр» — бронирование недоступно, историческая информация отображается FO.
