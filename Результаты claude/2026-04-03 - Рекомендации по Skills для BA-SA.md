# Рекомендуемые Skills для BA/SA задач

> Дата: 2026-04-03
> Контекст: рекомендации по инструментам (Skills) для работы на проекте TCO HDV/HDE Booking Tool

---

## Профиль пользователя

**Роль:** Бизнес-аналитик / Системный аналитик
**Инструменты:** Jira, Confluence, draw.io, Miro, PlantUML, BPMN 2.0, SQL

**Текущие задачи:**
- Выявление и документирование требований: интервью, use cases, user stories, SRS / ФТ / ТЗ
- Моделирование процессов AS-IS → TO-BE (BPMN, UML)
- Проектирование: БД, API-контракты, взаимодействие между системами

---

## Рекомендуемые Skills

### 1. `/pdf` — `anthropic-skills:pdf`
**Применение в задачах:**
- Извлечение текста из PDF-документов заказчика (BRD, протоколы встреч, процессные схемы)
- Парсинг `HDV HDE process.pdf`, `New HDV HDE Management Procedure.pdf`, резюме встреч
- Объединение/разбивка PDF-артефактов

**Когда использовать:** получил PDF от заказчика → нужно быстро извлечь требования или данные для анализа.

---

### 2. `/docx` — `anthropic-skills:docx`
**Применение в задачах:**
- Создание SRS, ФТ, ТЗ в формате `.docx` (требования к сдаче часто в Word)
- Генерация шаблонов: Use Case Specification, User Story, Test Case
- Чтение `.docx` от заказчика (например, `HDV HDE Business Requirements Document.docx`)

**Когда использовать:** нужно создать/прочитать формальный документ требований или сдаточный артефакт.

---

### 3. `/xlsx` — `anthropic-skills:xlsx`
**Применение в задачах:**
- Создание и ведение **Requirements Traceability Matrix (RTM)**
- Анализ `FINAL Master fleet file HDV HDE.xlsx` — структура данных по флоту
- Шаблоны: матрица ролей/прав, реестр требований, backlog

**Когда использовать:** работа с реестрами, матрицами трассировки, табличными данными по технике/требованиям.

---

### 4. `/pptx` — `anthropic-skills:pptx`
**Применение в задачах:**
- Презентации для стейкхолдеров: AS-IS → TO-BE обзор, архитектура интеграций
- Слайды для демо / sprint review
- Читать `.pptx` материалы от заказчика или партнёров

**Когда использовать:** нужно подготовить презентацию для встречи с TCO или командой.

---

### 5. `/schedule` — `anthropic-skills:schedule`
**Применение в задачах:**
- Автоматизация повторяющихся задач: еженедельная генерация шаблона протокола встречи
- Планирование регулярных проверок открытых вопросов (TBD-список)

**Когда использовать:** есть задача, которую нужно выполнять по расписанию.
