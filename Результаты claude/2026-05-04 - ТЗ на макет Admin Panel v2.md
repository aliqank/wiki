## Назначение документа

Документ описывает экраны, модальные окна и навигационную структуру Admin Panel для системы HDV/HDE Booking Tool.

**Что описывает:** состав элементов, состояния, поведение, взаимодействия внутри Admin Panel.
**Что НЕ описывает:** визуальный стиль (следовать существующей дизайн-системе), экраны ролей Requestor / Fleet Owner, API.

**Приоритет реализации макета:**
- Раздел «Типы техники» — реализовать в первую очередь (все экраны и модалки)
- Разделы 2–7 — реализовать согласно описаниям в этом документе

## 2. Экран AP-01: Список типов техники

**Маршрут:** Admin Panel → Типы техники

**Назначение:** просмотр, поиск и управление справочником типов техники. Каждый тип определяет набор динамических характеристик, которые автоматически отображаются в карточке техники, форме заявки и фильтрах поиска.

### 2.1 Элементы экрана

**Хедер страницы:**
- Заголовок: «Типы техники»
- Кнопка «+ Добавить тип» (primary, правый верхний угол) — переход на AP-02 (режим создания)

**Панель управления над таблицей:**
- Поле поиска по названию типа

**Таблица типов техники:**

| Колонка | Источник данных | Примечание |
|---------|----------------|------------|
| ≡ | — | Drag handle для изменения порядка (sortOrder). Tooltip: «Порядок влияет на список в интерфейсе» |
| Название типа | EquipmentTypes.name | |
| Тип мобильности | EquipmentTypes.mobilityType | Отображать русским названием (см. п. 15.1) |
| Требует транспорт | EquipmentTypes.requiresTransport | Иконка ✓ (да) / — (нет) |
| Характеристик | COUNT(EquipmentTypeProperties) | Число; при наведении — tooltip с перечислением |
| Единиц техники | COUNT(Equipments) | Число; информационно |
| Действия | — | Три иконки: Редактировать / Копировать / Удалить |

**Поведение строк:**
- Клик на строку → переход на AP-02 (режим редактирования)
- Drag & drop строки → изменение sortOrder (с сохранением без дополнительного подтверждения)

**Действие «Копировать»:**
- Создаёт дублирующую запись типа с именем «[Оригинал] (копия)»
- Копирует все базовые параметры и все характеристики
- Открывает AP-02 для нового типа в режиме редактирования (чтобы сразу переименовать)

**Действие «Удалить»:**
- Если «Единиц техники» = 0 → диалог подтверждения → soft delete
- Если «Единиц техники» > 0 → кнопка заблокирована, tooltip: «Нельзя удалить: к типу привязано N единиц техники»

**Пустое состояние (нет типов):**
- Иконка + текст: «Типы техники не добавлены»
- Кнопка «Добавить первый тип»

## 3. Экран AP-02: Карточка типа техники

**Маршрут (создание):** AP-01 → кнопка «+ Добавить тип»
**Маршрут (редактирование):** AP-01 → клик на строку или иконка «Редактировать»

**Два режима:** «Новый тип техники» / «Редактировать: [Название]»

### 3.1 Хедер карточки

- Хлебные крошки: «Типы техники → [Название]» (или «Новый тип» при создании)
- Кнопка «Копировать тип» (вторичная, рядом с хлебными крошками) — действие аналогично AP-01
- Кнопки управления (правый угол): **«Отменить»** (выйти без сохранения) | **«Сохранить»** (primary)

### 3.2 Блок A: Базовые параметры

Одинаковы для всех типов техники. Всегда отображаются вверху карточки.

| Поле | Элемент UI | Обязательно | Описание / Значения |
|------|-----------|-------------|---------------------|
| Название типа | Text input | Да | Уникальное. Пример: «Компрессор», «Экскаватор», «Самосвал» |
| Тип мобильности | Select | Да | 4 значения — см. п. 15.1 |
| Требует транспортировку | Toggle (Да / Нет) | Да | TRUE = в процессе бронирования запускается подпроцесс запроса транспорта для доставки (Unwheeled flow) |
| Порядок отображения | Number input | — | Авто-заполняется при создании (конец списка). Редактируемо вручную |

**Подсказка под полем «Требует транспортировку»:** «При включении система автоматически запросит транспортную технику для доставки при бронировании»

### 3.3 Блок B: Характеристики типа

Администратор задаёт набор динамических характеристик для данного типа техники. Характеристики **автоматически** появятся:
- в карточке техники (если isVisibleInCard = true)
- в форме заявки Requestor-а
- в фильтрах поиска (если isFilterable = true)

**Подзаголовок блока:** «Характеристики»

**Подсказка под подзаголовком:** «Характеристики автоматически отображаются в карточке техники, форме заявки и фильтрах поиска Requestor-а — в зависимости от выбранного типа техники»

#### Таблица добавленных характеристик

| Колонка | Источник | Описание |
|---------|----------|----------|
| ≡ | sortOrder | Drag handle для изменения порядка внутри типа |
| Название | Properties.name | |
| Ед. измерения | MeasurementUnits.displayName | «—» если тип значения не требует единицы |
| Тип значения | Properties.dataType | Русское название — см. п. 15.2 |
| Допустимые значения | PropertyEnumValues | Только для типа «Перечисление». Показать первые 3 значения + «...ещё N» / кнопка «Просмотреть» |
| Обязательная | isRequired | Чекбокс (можно изменять прямо в таблице) |
| Фильтруемая | isFilterable | Чекбокс. Tooltip: «Характеристика появится как фильтр в поиске» |
| Видима в карточке | isVisibleInCard | Чекбокс. Tooltip: «Характеристика отображается в карточке техники» |
| Действия | — | Редактировать (иконка карандаш) / Удалить (иконка корзина) |

**Пустое состояние блока B** (характеристик нет):
- Текст: «Характеристики не добавлены»
- Подсказка: «Добавьте характеристики — они будут отображаться в карточке техники и фильтрах поиска»

#### Кнопки под таблицей

- **«+ Добавить характеристику»** — открывает M-AP-01
- **«Добавить из другого типа»** — открывает M-AP-02

#### Действие «Удалить» характеристику из типа

- Если характеристика используется **только этим типом** → удаляется без предупреждения (только из EquipmentTypeProperties)
- Если характеристика используется в **других типах** → диалог: «Характеристика "[Название]" также используется в: [список типов]. Удалить только для этого типа?» → Да / Отмена

## 4. Модальное окно M-AP-01: Добавление / редактирование характеристики в типе

**Открывается из:** AP-02 → «+ Добавить характеристику» или иконка «Редактировать» у характеристики в таблице

**Заголовок:** «Добавить характеристику» / «Редактировать характеристику»

### 4.1 Два таба

| Таб | Описание |
|-----|----------|
| **Новая характеристика** | Создать новую характеристику в общем справочнике Properties + добавить к текущему типу |
| **Из справочника** | Выбрать уже существующую характеристику из Properties (переиспользование между типами) |

### 4.2 Содержимое модалки

**Секция «Характеристика» (зависит от выбранного таба):**

*Таб «Новая характеристика»:*
- Название — text input, обязательно (пример: «Объём ресивера», «Тип привода»)
- Тип значения — select, обязательно (см. п. 15.2)
- Единица измерения — select из MeasurementUnits (показывается **только** если тип = «Число целое» или «Число дробное»)
- Допустимые значения — редактируемый список (показывается **только** если тип = «Перечисление»):
  - Поле ввода нового значения + кнопка «Добавить»
  - Каждое значение: текст + drag handle + кнопка удалить
  - Drag & drop для изменения порядка (sortOrder в PropertyEnumValues)
  - Минимум 2 значения для сохранения

*Таб «Из справочника»:*
- Поле поиска — поиск по названию в справочнике характеристик (Properties)
- После выбора:
  - Название — read-only
  - Тип значения — read-only
  - Единица измерения — read-only
  - Допустимые значения (если enum) — read-only список
  - Пояснение: «Тип и единица заданы в справочнике характеристик. Для изменения откройте раздел "Характеристики"»

**Секция «Настройки отображения» (одинакова для обоих табов):**

| Элемент | Поле БД | Описание |
|---------|---------|----------|
| Обязательная | isRequired | Чекбокс. «Характеристика обязательна при создании единицы техники» |
| Фильтруемая | isFilterable | Чекбокс. «Характеристика будет доступна как фильтр при поиске техники» |
| Видима в карточке техники | isVisibleInCard | Чекбокс. «Характеристика отображается в карточке единицы техники» |

**Кнопки:** Отменить | **Добавить** (при добавлении) / **Сохранить** (при редактировании)

## 5. Модальное окно M-AP-02: Импорт характеристик из другого типа

**Открывается из:** AP-02 → «Добавить из другого типа»

**Заголовок:** «Импорт характеристик из другого типа техники»

**Структура:**
1. **Выбор источника** — select / поиск по названию типа. В списке — все типы, кроме текущего
2. **Список характеристик источника** (появляется после выбора типа):
   - Таблица с чекбоксами:

     | ☐ | Название | Ед. изм. | Тип значения | Обязательная | Фильтруемая | Видима в карточке |
     |---|----------|----------|-------------|-------------|------------|-----------------|
     | ☑ (заблок.) | Объём ресивера | л | Число дробное | ✓ | ✓ | ✓ |
     | ☐ | Рабочее давление | бар | Число дробное | — | ✓ | ✓ |

   - Характеристики, **уже добавленные** к текущему типу: чекбокс отмечен и заблокирован, tooltip: «Уже добавлена»
   - Возможность выбрать все / снять всё
3. **Счётчик выбранных** над кнопками: «Выбрано: N характеристик»

**Кнопки:** Отменить | **Добавить выбранные (N)** (primary, неактивна при N = 0)

**Поведение после добавления:** импортированные характеристики наследуют настройки isRequired / isFilterable / isVisibleInCard из источника. Их можно изменить в AP-02 через таблицу или иконку «Редактировать».

## 7. Модальное окно M-AP-03: Создать / редактировать характеристику

**Открывается из:** AP-03 → кнопка «+ Добавить характеристику» или иконка «Редактировать»

**Заголовок:** «Новая характеристика» / «Редактировать характеристику»

**Назначение:** создание или редактирование характеристики в глобальном справочнике без привязки к конкретному типу техники. Созданная характеристика становится доступна для выбора в AP-02 (таб «Из справочника»).

### 7.1 Поля формы

| Поле | Элемент UI | Обязательно | Описание |
|------|-----------|-------------|----------|
| Название | Text input | Да | Уникальное. Пример: «Объём ресивера», «Тип привода», «Наличие обогрева» |
| Тип значения | Select | Да | Значения — см. п. 15.2. При редактировании: **заблокирован**, если характеристика используется хотя бы в одном типе |
| Единица измерения | Select из MeasurementUnits | Нет | Отображается **только** для типов «Число целое» и «Число дробное» |
| Допустимые значения | Редактируемый список | — | Отображается **только** для типа «Перечисление»; минимум 2 значения |

**Допустимые значения (только для «Перечисление»):**
- Поле ввода нового значения + кнопка «Добавить»
- Каждое значение: текст + drag handle + кнопка удалить
- Drag & drop для изменения sortOrder в PropertyEnumValues

**Предупреждение при редактировании типа значения (если характеристика используется в типах):**
> «Тип значения нельзя изменить: характеристика используется в N типах техники. Для изменения создайте новую характеристику»

**Кнопки:** Отменить | **Создать** (при создании) / **Сохранить** (при редактировании)

## 8. Экран AP-04: Список флотов

**Маршрут:** Admin Panel → Флоты и доступы

**Назначение:** просмотр всех парков техники и управление правами доступа к ним. Данные флотов синхронизируются из внешней системы — создание и удаление недоступно.

### 8.1 Элементы экрана

**Хедер страницы:**
- Заголовок: «Флоты и доступы»

**Панель управления над таблицей:**
- Поле поиска по названию флота
- Фильтр «Тип флота» — select (Все / Maintenance / Construction / TFM / SCM Logistics / External BP)

**Таблица флотов:**

| Колонка | Источник данных | Примечание |
|---------|----------------|------------|
| Название | Fleets.name | |
| Тип | Fleets.type | Русское название — см. п. 15.3 |
| AAD-группа | Fleets.aadGroupId | Идентификатор группы в Azure Active Directory |
| Единиц техники | COUNT(Equipments WHERE fleetId = ...) | Число; информационно |
| Управляющих | COUNT(активных FleetManagePermissions) | Активные = expiresAt IS NULL OR expiresAt ≥ сегодня |
| Действия | — | Иконка «Управление доступом» — переход на AP-05 |

**Поведение строки:**
- Клик на строку → переход на AP-05 (карточка флота)

**Примечание под таблицей:**
> «Флоты синхронизируются из внешней системы Master Fleet. Создание и удаление недоступно в Admin Panel.»

## 16. Состояния и валидация

### 16.1 Общие состояния форм (AP-02, AP-08, M-AP-*)

| Ситуация | Поведение |
|----------|-----------|
| Форма не изменялась | Кнопка «Сохранить» / «Создать» неактивна |
| Обязательное поле пустое | Поле подсвечено красным; кнопка заблокирована |
| Нажали «Отменить» с несохранёнными изменениями | Диалог: «Изменения не сохранены. Покинуть страницу?» — Остаться / Покинуть |

### 16.2 Удаление типа техники (AP-01)

| Условие | Результат |
|---------|-----------|
| К типу не привязана техника | Диалог подтверждения → удаление (soft delete) |
| К типу привязана техника (N единиц) | Кнопка «Удалить» заблокирована. Tooltip: «Нельзя удалить: к типу привязано N единиц техники» |

### 16.3 Удаление характеристики из типа (AP-02)

| Условие | Результат |
|---------|-----------|
| Характеристика используется только этим типом | Удаление без предупреждения |
| Характеристика используется другими типами | Диалог: «Характеристика "[Название]" также используется в: [список типов]. Удалить только для текущего типа?» |

### 16.4 Удаление характеристики из справочника (AP-03)

| Условие | Результат |
|---------|-----------|
| Не используется ни в одном типе | Диалог подтверждения → удаление |
| Используется в 1 или более типах | Кнопка заблокирована. Tooltip: «Нельзя удалить: используется в N типах: [список]» |

### 16.5 Редактирование типа значения характеристики (M-AP-03)

| Условие | Результат |
|---------|-----------|
| Характеристика не привязана ни к одному типу | Поле «Тип значения» редактируемо |
| Характеристика используется в 1 или более типах | Поле «Тип значения» заблокировано. Inline-предупреждение: «Тип значения нельзя изменить: характеристика используется в N типах» |

### 16.6 Удаление права управления флотом (AP-05)

| Условие | Результат |
|---------|-----------|
| Любое | Диалог подтверждения с именем пользователя → отзыв права |

### 16.7 Удаление единицы измерения (AP-06)

| Условие | Результат |
|---------|-----------|
| Не используется в характеристиках | Диалог подтверждения → удаление |
| Используется в 1 или более характеристиках | Кнопка заблокирована. Tooltip: «Нельзя удалить: используется в N характеристиках» |
