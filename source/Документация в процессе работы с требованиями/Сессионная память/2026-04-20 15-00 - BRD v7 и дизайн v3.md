## Принятые решения

- **OQ-NEW-I CLOSED:** Priority — атрибут Work Order (Request), не шага и не единицы техники; все Work Center-ы в одном WO имеют одинаковый приоритет
- **OQ-NEW-J CLOSED:** Департамент в отчётах определяется по **Equipment**, а не по Fleet Owner
- **Default WO / Default WC (FR-NEW-51):** Для команд без JDE (Logistics и другие) — чекбокс "Default Work Order" на форме заявки; номер JDE не требуется
- **Дашборд утилизации — 3 таба:** Моточасы / Километраж / Комбайн (максимум из двух)
- **Цветовой градиент:** 0% → красный, 50% → жёлтый, 100% → зелёный (плавный)
- **Ремонтные дни:** иконка гаечного ключа; данные из JDE (commitment/planned/completed date); исключаются из расчёта среднего
- **Ручной ввод ремонта для BP/non-JDE техники:** отложен на Phase 2
- **Утилизация из трекеров:** считается вне зависимости от наличия заявок в системе
- **Сравнение утилизации и заявок:** Phase 2
- **GIS-карта (FR-NEW-61, FR-NEW-62):** iframe от GIS-команды; чекбоксы в списке техники; tooltip: текущий WO + утилизация за день; кнопка расширить карту
- **Изображения техники на дашборде утилизации:** убрать; добавить иконки по типу техники
- **История заявок для Requestor (FR-NEW-52):** отдельная страница с завершёнными заявками
- **OQ-NEW-K (route tracking):** открытый вопрос — решение флитоунеров к 20.04
