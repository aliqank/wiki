Моя задача - описать ТЗ для дизайнера для разработки макета админ. панели.

Админ панель может включать в себя много функционала (нужно заложить "заглушки").

Но сейчас требуется:
- Управление списком типов техники
- Создание, редактирование типа техники
- В карточке типа техники должны быть 2 блока:
  - базовые параметры (отображаются для всех типов техники одинаково)
  - специфические параметры: возможность добавлять параметры (выбор названия параметра, ед. измерения параметра, тип значений (текст, число, перечисление и т.д.), список значений, если пользователь выбрал перечисление)
  - также добавить возможность добавить спец. параметры из уже существующих типов, и добавить возможность скопировать карточку типа техники для создания новой
