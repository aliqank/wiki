## Промпт

---

Design a set of high-fidelity UI mockups for an enterprise web application called **TCO HDV/HDE Booking Tool** — a heavy equipment and vehicle booking system for Tengizchevroil (TCO), a large oil production company in Kazakhstan.

**Design requirements:**
- Style: enterprise, clean, professional
- Color scheme: grayscale (white backgrounds, gray surfaces, dark gray text, charcoal accents); use a single muted accent color (e.g. slate blue or teal) only for primary action buttons and active status badges
- Language: English
- Platform: web application (desktop-first, 1440px wide)
- Component style: consistent use of tables, cards, status badges, form fields, breadcrumbs, and a left sidebar navigation

---

### System context

The system allows TCO employees to book heavy-duty vehicles and equipment from internal and external fleets. Key roles: **Requestor** (any TCO employee who needs equipment), **Fleet Owner / FO** (approves or rejects bookings), **Administrator** (manages the system). Equipment has a priority system (P1–P4) and a lifecycle: Draft → Submitted → Confirmed / Rejected / Withdrawn → In Progress → Completed.

Equipment is classified as:
- **Mobile** — trucks, vehicles, generators on wheels
- **Stationary** — compressors, light towers, heat guns, man-lifts — require a **trailer (tral)** for delivery

---

### Page 1 — Create Request (Requestor)

A form page for submitting a new equipment booking request.

**Layout:** Left sidebar navigation + main content area with a multi-section form.

**Form sections:**

1. **Equipment** — equipment type selector (dropdown or searchable list showing equipment category icons), quantity field; if selected type is **Stationary**, show an inline information banner: _"A trailer (tral) booking will be automatically added to this request"_
2. **Booking Period** — date picker for Start Date / End Date, time pickers for Start Time / End Time
3. **Delivery Details** — text field for Delivery Location / Work Site
4. **Priority** — radio group or segmented control: P1 (Critical) / P2 (High) / P3 (Medium) / P4 (Low); each with a colored badge
5. **Cost Center** — dropdown (pre-filled from user profile, editable)
6. **Comments** — optional textarea

**Action buttons:** "Submit Request" (primary) · "Save as Draft" (secondary) · "Cancel" (text link)

**Bottom of page:** Summary card showing selected equipment type, period, and estimated delivery location before submission.

---

### Page 2 — My Requests — List (Requestor)

A list page showing all requests submitted by the current user.

**Layout:** Left sidebar + full-width table with filters above.

**Filters bar (top):** Status (multi-select dropdown: All / Draft / Submitted / Confirmed / Rejected / Withdrawn / In Progress / Completed) · Date range picker · Priority filter · Search by request number

**Table columns:**
- Request # (link to detail)
- Submitted At (date + time)
- Booking Period (from → to)
- Equipment Type(s) (comma-separated, max 2 shown + "+N more")
- # of Equipment Types
- Priority (colored badge: P1/P2/P3/P4)
- Status (colored badge)
- Actions (icon button: View)

**Empty state:** Illustration + text "No requests yet. Create your first request." + button "Create Request"

---

### Page 3 — Request Detail — Requestor View

A read-only detail page for a submitted request, showing full status and FO decisions.

**Layout:** Left sidebar + two-column layout (main content left, status sidebar right).

**Header:** Request number + created date + "Withdraw Request" button (only if status is Submitted)

**Left column — Request Details:**
- Priority badge
- Booking period (dates + times)
- Delivery location
- Cost Center
- Comments

**Equipment section (table):**
| Equipment Type | Quantity | Status | Assigned Unit | Fleet Owner |
|---|---|---|---|---|
| Generator 500kVA | 1 | Confirmed | TCO-GEN-042 | A. Seitkali |
| Light Tower | 2 | Pending | — | — |

If equipment type is stationary: show "Tral required" tag next to it.

**Right column — Status Timeline:**
Vertical timeline showing:
- Request Submitted — [date/time]
- Sent to Fleet Owner — [date/time]
- FO Response — Confirmed / Rejected + reason (if rejected)
- Booking Confirmed / Rejected

If rejected: show rejection reason in a highlighted callout box (e.g. light red background).

---

### Page 4 — Incoming Requests — Fleet Owner View

A list page showing all requests that require the FO's attention.

**Layout:** Left sidebar + full-width table.

**Tabs at top:** "Pending" (default) · "All Requests"

**Filters bar:** Priority · Date range · Equipment type · Search

**Table columns:**
- Request # (link)
- Requestor Name
- Equipment Type(s)
- Booking Period
- Delivery Location
- Priority (badge: P1 red / P2 orange / P3 yellow / P4 gray)
- Submitted At
- Status badge
- Actions: "Review" button

**Visual emphasis:** P1 rows have a subtle red left border; P2 rows have orange left border.

---

### Page 5 — Request Detail — Fleet Owner View

A detail page where FO reviews a request and makes a decision.

**Layout:** Left sidebar + main content with two action buttons at top.

**Header:** Request # · Requestor name + department · Submitted date
**Primary actions (top right):** "Confirm" button (green/accent) · "Reject" button (outlined red)

**Sections:**
1. **Request Info:** Priority badge, booking period, delivery location, cost center, comments
2. **Equipment Requested (table):**
   | Equipment Type | Quantity | Mobility | Notes |
   |---|---|---|---|
   | Compressor 185CFM | 1 | Stationary | Tral required |
3. **Fleet Availability hint:** small inline indicator showing how many units of requested type are currently free in the FO's fleet
4. **History / Audit log** (collapsed by default): previous FO actions on this request if any

**On click "Confirm":** Opens modal M-06 (Assign Equipment)
**On click "Reject":** Opens modal M-05 (Rejection Reason)

---

A dedicated page (or full-screen modal) for selecting specific equipment units to assign to a request.

**Layout:** Split view — left: request summary card; right: equipment selection.

**Left panel — Request Summary:**
- Equipment type needed
- Booking period
- Delivery location
- Priority

**Right panel — Available Equipment (table):**
| Unit ID | Name / Model | Current Status | Location | Last Inspection | Select |
|---|---|---|---|---|---|

---

### Modal M-01 — Tral Notice

Triggered automatically when user selects a **Stationary** equipment type on the Create Request page.

**Style:** Inline information banner (not a blocking modal) — light gray background, info icon, dismissible.

**Text:** _"This equipment type is stationary and requires transportation. A trailer (tral) booking will be automatically added to your request."_

---

### Modal M-05 — FO Rejection Reason

Triggered when FO clicks "Reject" on the Request Detail page.

**Style:** Centered modal, medium size.

**Content:**
- Title: "Reject Request"
- Subtitle: "Please provide a reason for rejection. This will be visible to the Requestor."
- Textarea: "Rejection reason" (required, min 10 characters, shows character count)
- Checkbox: "Equipment is unavailable for this period" / "Equipment already assigned to another request" / "Other" (pre-filled options to speed up input)
- Buttons: "Submit Rejection" (red, primary) · "Cancel" (secondary)

---

### Modal M-03 — Request Submitted — Success

Shown after successful request submission.

**Style:** Centered modal, small.

**Content:**
- Checkmark icon (green or dark gray)
- Title: "Request Submitted"
- Request number in large monospace font: #REQ-2026-00342
- Text: "Your request has been sent to the Fleet Owner. You will be notified once a decision is made (within 24 hours)."
- Button: "View My Request" (primary) · "Create Another Request" (secondary)

---

### Modal M-04 — Withdraw Request

Triggered when Requestor clicks "Withdraw Request".

**Style:** Centered modal, small.

**Content:**
- Warning icon
- Title: "Withdraw Request?"
- Text: "This will cancel your request. This action cannot be undone."
- Buttons: "Yes, Withdraw" (destructive / dark gray) · "Keep Request" (secondary)

---

**Additional design notes:**
- Navigation sidebar contains: Dashboard · My Requests · Create Request (for Requestor role); Incoming Requests · Fleet (for FO role)
- All tables support column sorting
- Status badges use consistent styling: rounded pill shape, uppercase text, muted background fill
- Priority badges: P1 = red, P2 = orange, P3 = amber, P4 = gray
- Use a top notification bar for system alerts (e.g. "FO has not responded in 24h — reminder sent")
- All form fields use standard enterprise patterns: label above field, helper text below, red asterisk for required
