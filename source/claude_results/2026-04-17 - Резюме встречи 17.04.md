## 3. Дашборд утилизации

### 3.1 Три вкладки (табы)

| Таб | Содержание |
|-----|-----------|
| **Моточасы** | Утилизация только по моточасам |
| **Километраж** | Утилизация только по пробегу |
| **Комбайн** | Максимальное из двух значений (по формуле из Master Fleet File) |

> Техника HDE — только моточасы; HDV — только пробег; при наличии обоих → отображать максимальное.

### 3.2 Цветовая схема (градиент)

- **0%** — красный
- **50%** — жёлтый
- **100%** — зелёный
- Плавный градиент между значениями (не три дискретных цвета)

### 3.3 Ремонтные дни

- Дни, когда техника была на ремонте, **отмечать иконкой гаечного ключа** (не красным — чтобы не смешивать с цветом низкой утилизации)
- Данные из **JDE** (проверить): `commitment date` (начало ремонта) + `planned date` (плановое завершение) + `completed date` (фактическое завершение)
- Ремонтные дни **исключаются** из расчёта средней утилизации
- Для **BP-техники** и техники вне JDE (не все ремонты есть в системе) — ручной ввод ремонтных дат через FO **отложить на Phase 2**; пока использовать только данные JDE

### 3.4 Дополнительные колонки

| Колонка | Описание |
|---------|---------|
| **Целевое значение** | Максимальная утилизация, заданная FO (моточасы/км в сутки). Например: 2 000 моточасов |
| **Среднее за период** | Среднее по выбранному диапазону (ремонтные дни исключать из рассчета) |

### 3.5 Сортировка и навигация

- Сортировка по **среднему за период** (от большего к меньшему)
- Переключение диапазона: **по дням** / **по месяцам** (выбор через фильтр сверху)

### 3.6 Фильтр «Принадлежность»

Добавить в левый сайдбар дашборда: **TCO Owned** / **Long-term rented**

### 3.7 Изображения и иконки

- **Убрать** фотографии техники с дашборда утилизации (замедляют загрузку)
- **Добавить** пиктограммы типа техники (кран, погрузчик, грузовик и т.д.) 

### 3.8 Источник данных утилизации

Утилизация **считается по данным трекеров**, **вне зависимости** от наличия заявок в системе.  


### 3.9 Сравнение утилизации и количества заявок (Phase 2)

Предложение — показывать рядом с утилизацией количество букирований за день (для выявления аномалий: техника едет, а заявок нет).  
**Решение:** включить в **Phase 2**. Сейчас фокус — на самой утилизации.

**Решение (предложено участниками и принято):**

- При выборе дефолтного WO — система не требует ввода номера из JDE
- Аналогично — **«Default Work Center»** для команд без рабочих центров
