# Глоссарий терминов — TCO HDV/HDE Booking Tool

**Дата создания:** 2026-04-08  
**Тип документа:** Живой глоссарий (обновляется по мере уточнения терминологии)  
**Источники:** BRD (RU/EN), транскрипции встреч 02.04–08.04, реестр требований

---

## 1. Основные сущности системы

| Термин (EN) | Термин (RU) | Определение |
|-------------|-------------|-------------|
| **Equipment** | Оборудование | Отдельный актив (единица HDV/HDE), который может быть забронирован. Принадлежит парку и наследует цепочку согласования от своего Fleet Owner. |
| **Fleet** | Парк | Логическая группа оборудования, принадлежащая Fleet Owner-у. Внутренний парк: ТО, Строительство, TFM и др. Внешний парк: название Делового партнёра. |
| **Request** | Заявка | Контейнер, объединяющий несколько бронирований оборудования. Имеет уникальный ID, статус, метаданные. |
| **Unfinished Request** | Незавершенная заявка | Заявка, которая еще не перешла в terminal status и поэтому должна отображаться в списке `Мои заявки`. Для текущего scope термин означает request со статусом `Draft`, `Submitted` или `InProgress`. Заявки в статусе `Closed` относятся к completed/history flow и в список незавершенных заявок не входят. |
| **Regular Request** | Обычная заявка | Заявка, создаваемая Requestor-ом вручную в системе. |
| **Service Work Request (SWR)** | Заявка на сервисные работы | Заявка, создаваемая системой автоматически через API на основе Work Order в JDE E1. Подаётся SWP. |
| **Booking** | Бронирование | Одна единица оборудования в рамках заявки с диапазоном дат (from–to). Обрабатывается индивидуально. |

## 2. Роли

| Термин (EN) | Термин (RU) | Определение |
|-------------|-------------|-------------|
| **Requestor** | Заявитель | Любой пользователь в сети TCO. Создаёт заявки на технику. Для Rented on-demand требуется роль RWA Initiator. |
| **Fleet Owner (FO)** | Владелец парка | Лицо, ответственное за согласование бронирований в рамках своего парка. |
| **Internal Fleet Owner** | Внутренний FO | FO внутреннего парка (Own и Long-term rented техника). Определяется по группе AAD. |
| **External Fleet Owner (FO BP)** | Внешний FO | FO внешнего парка (Rented on-demand техника делового партнёра). Управляется через приглашения от Администратора. |
| **CC Owner** | Владелец ЦЗ | Владелец центра затрат. Согласует бронирования Rented on-demand. Определяется через PSWS + DOA. |
| **DPA** | ДПА | Delegated Proxy Approver — делегированное полномочное лицо CC Owner-а. |
| **Service Work Processor (SWP)** | Обработчик заявок на сервисные работы | Роль, управляемая через AAD. Работает с SWR: назначает технику и подаёт заявку. |
| **Administrator** | Администратор | Роль Логистики (process owner). Управляет парками, шаблонами, пользователями, настройками системы. |
| **Approver** | Согласующий | Обобщённое название для Fleet Owner и/или CC Owner, которые подтверждают/отклоняют бронирования. |
| **Contract Specialist** | Специалист по контрактам | Участвует в оффлайн-процессе Rented on-demand: получает запросы, собирает предложения BP. |

## 3. Классификация техники

### 3.1 По владению (категории)

| Категория (EN) | Категория (RU) | Определение | Цепочка согласования |
|----------------|----------------|-------------|----------------------|
| **Own** | Собственная | Техника, принадлежащая TCO | Только Internal FO |
| **Long-term rented** | Долгосрочная аренда | Долгосрочная аренда у BP; новая авторизация не требуется | Только Internal FO |
| **Rented on-demand** | Аренда по запросу | Аренда у BP по отдельному запросу; требует авторизации (RWA/SR) | CC Owner → External FO BP |

### 3.2 По мобильности (типы HDV/HDE)

| Тип (EN) | Тип (RU) | Определение | Примеры |
|----------|----------|-------------|---------|
| **Self-propelled motorized (HDV/HDE)** — Wheeled or Tracked | Самоходная техника (колёсная / гусеничная) | Имеет собственный двигатель, передвигается самостоятельно без буксировки. | Бульдозеры, самосвалы, автогрейдеры, тракторы, экскаваторы, крановые установки на колёсном ходу |
| **Not self-propelled motorized HDE** | Несамоходное моторизованное оборудование | Имеет двигатель для рабочих функций (бурение, подъём), но не может передвигаться самостоятельно. Требует буксировки/перевозки. | Компрессоры на прицепе, передвижные генераторы, гидравлические насосы, осветительные мачты |
| **Stationary HDE** | Стационарное оборудование | Установлено стационарно или работает на одном месте. Может иметь/не иметь двигатель. Перемещение невозможно. | Стационарные генераторы, промышленные котлы, компрессоры |
| **Non-motorized HDE** | Немоторизованное оборудование | Не имеет двигателя, работает от внешнего источника питания или вручную. | Прицепы, ручной инструмент, контейнеры без электропитания, тележки |

> **Примечание:** *Unwheeled техника* = Not self-propelled motorized HDE + Non-motorized HDE.  
> Для доставки требует **техники для перемещения Unwheeled техники** (трал и т.п.).  
> Stationary HDE исключается — её перемещение невозможно.

### 3.3 По статусу использования (Usage Status)

| Статус (EN) | Статус (RU) | Определение |
|-------------|-------------|-------------|
| **Shared without conditions** | Общее без условий | Техника может быть передана пользователям на запрошенные даты без каких-либо условий. Видима Requestor-у в поиске. |
| **Shared with conditions** | Общее с условиями | Техника доступна, но FO может реаллоцировать её на заявки с более высоким приоритетом. Отображается с визуальным маркером. Requestor не может на неё полностью полагаться. |
| **Assigned** | Закреплено | Техника закреплена за конкретным объектом/локацией и не может быть передана другим пользователям (ежедневное использование или экстренная поддержка). **Не отображается** в поиске Requestor-а. Обоснование обязательно. |

## 4. Процессы и документы

| Термин (EN) | Термин (RU) | Определение |
|-------------|-------------|-------------|
| **Work Order (WO)** | Рабочее задание | Документ в JDE E1. Каждый «Шаг» WO порождает отдельную SWR в Booking Tool. |
| **JDE Work Order** | Рабочее задание JDE | Обязательное поле в заявке. Используется FO для определения точки доставки техники. |
| **SR (Service Request)** | Заявка на услугу | Номер из системы SMART/DCT, который линкуется с записью в Booking Tool при Rented on-demand. |
| **RWA (Request for Work Authorization)** | Запрос на авторизацию работ | Документ, необходимый для работы с внешним (BP) парком. RWA Initiator — роль в DCT, дающая право на Rented on-demand. |
| **Freeze** | Заморозка | Статус техники, при котором она недоступна для бронирования (например, на период КАП-ремонта). Устанавливается FO. |
| **Escalation** | Эскалация | Автоматическое перенаправление при отсутствии ответа FO в течение тайм-аута. |
| **Early Completion** | Досрочное завершение | Завершение бронирования до плановой даты окончания. Для Rented on-demand — Requestor; для Own/Long-term rented — FO. |
| **Extension** | Продление | Продление уже подтверждённого бронирования. Инициируется Requestor-ом. |
| **Bid** | Предложение (тендерное) | Ответ BP на запрос Rented on-demand. Отображается Requestor-у анонимно (Bidder 1 / Bidder 2 / ...). |

## 6. Статусы бронирования

| Статус (EN) | Статус (RU) | Описание |
|-------------|-------------|----------|
| **Draft** | Черновик | Создан, не подан |
| **Submitted** | Подано | Подано на согласование |
| **Confirmed** | Подтверждено | Согласовано FO (и CC Owner для Rented on-demand) |
| **Rejected** | Отклонено | Отклонено согласующим |
| **Withdrawn** | Отозвано | Отозвано Requestor-ом |
| **Extended** | Продлено | Бронирование продлено Requestor-ом после подтверждения |
| **Early Completed** | Досрочно завершено | Завершено до плановой даты |
| **Completed** | Завершено | Закрыто по плановой дате |

## 7. Внешние системы и интеграции

| Аббревиатура | Расшифровка | Роль в системе |
|-------------|-------------|----------------|
| **JDE E1** | JD Edwards EnterpriseOne | ERP-система TCO. Источник Work Order-ов для SWR. |
| **DCT** | Digital Contractor Timesheet | Система TCO. Источник роли RWA Initiator. Используется для Rented on-demand (RoutMaint + MajMaint). |
| **PSWS** | TCO White Page / People Search Web Service | Справочник сотрудников TCO. Источник данных о ЦЗ Заявителя и роли CC Owner. |
| **DOA** | Delegation of Authority | Система делегирования полномочий. Источник данных о DPA (делегированных полномочных лицах). |
| **DataLake** | Data Lake TCO | Платформа хранения данных. Используется для отчётности и аналитики. |
| **AAD** | Azure Active Directory | Identity-провайдер TCO. Управляет ролями FO, SWP, Admin, RWA Initiator. |
| **GIS / Atlas** | Геоинформационная система TCO | Встраивается через iframe + URL параметры. Синхронизация по equipment ID + Azure SSO. |
| **WIALON** | Wialon | Платформа GPS-мониторинга. Заблокирована для использования (cyber security assessment). |
| **IVMS** | In-Vehicle Monitoring System | Трекеры на технике TCO (регистрационный номер). |
| **Vega** | Vega device | Альтернативная система трекеров (ID устройства). |

## 8. Технические сокращения и аббревиатуры

| Термин | Расшифровка / Пояснение |
|--------|-------------------------|
| **HDV** | Heavy Duty Vehicle — тяжёлая техника (транспортные средства) |
| **HDE** | Heavy Duty Equipment — тяжёлое оборудование |
| **TCO** | Tengizchevroil — клиент, оператор нефтяного промысла |
| **BP** | Business Partner / Деловой партнёр — внешний подрядчик или поставщик техники |
| **ЦЗ / CC** | Центр затрат / Cost Center |
| **КАП** | Капитальный ремонт (основание для заморозки техники) |
| **RBAC** | Role-Based Access Control — управление доступом на основе ролей |
| **ACR** | Architecture and Cybersecurity Review — оценка кибербезопасности (тир: Low Risk) |
| **TFM** | Total Facilities Management — одно из подразделений TCO (владелец парка) |
| **IIoT** | Industrial Internet of Things — промышленный IoT; трекеры Teltonika 250/650 |
