## 1. Уточнение модели данных

Закреплена иерархия объектов в системе:

```
Request
 └── Work Center (Шаг)
      └── Equipment
           └── Fleet
                └── Fleet Owner
```

**Ключевые ограничения:**
- Один тип Equipment работает только по **одному** Work Center
- В одном Work Center может работать **несколько** типов Equipment

## 3. Особенности логистики

Логистика **не работает по Work Order** в JDE и не имеет Work Center.  
**Решение:** поля WO и WC сделать необязательными для подразделения «Логистика».

## 6. Страница «Подать заявку» — интеграция с JDE

**Новый функционал:** кнопка/блок «Выбрать Work Order из JDE»

**Сценарий:**
1. Пользователь нажимает «Выбрать WO из JDE»
2. Система отображает список WO с атрибутами (см. ниже)
3. Пользователь выбирает WO
4. Система формирует **draft заявки**
5. Пользователь дозаполняет поля по технике и времени

**Данные по Work Order из DataLake (требования к интеграции):**

| Поле              | Описание                          |
|-------------------|-----------------------------------|
| Номер WO          |Номер заявки в JDE E1 |
| Наименование WO   | Название заявки в JDE E1|
| Статус            | Статус заявки в JDE E1|
| Описание статуса  | Текстовое описание статуса заявки в JDE E1|
| Приоритет| Приоритет заявки в JDE E1|
| Work Center       | Шаги (код)                        |
| Название шага     |Описание шага |
| Объёмы шагов      | Количество требуемых единиц техники|
| Диапазон дат      | Дата начала / Дата завершения|
