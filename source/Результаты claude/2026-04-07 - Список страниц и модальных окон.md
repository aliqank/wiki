# Список страниц и модальных окон — TCO HDV/HDE Booking Tool
**Дата:** 2026-04-07
**Тип документа:** Реестр экранов UI

---

## Роли пользователей

| Роль | Описание |
|------|---------|
| **Requestor** | Любой сотрудник TCO, создающий заявку на технику |
| **Fleet Owner (FO)** | Владелец парка техники — подтверждает/отклоняет заявки |
| **CC Owner** | Владелец Cost Center — согласует привлечение внешней техники (Cat 3) |
| **Contract Specialist** | Сотрудник Central Contract Group — ведёт тендер Cat 3 |
| **Administrator** | Логистика TCO — управляет системой |

---

## Страницы

### Роль: Requestor

| # | Страница | Описание |
|---|---------|---------|
| P-01 | **Dashboard / Home** | Сводка: активные заявки, уведомления, быстрая кнопка создания заявки |
| P-02 | **Create Request** | Форма создания новой заявки: тип техники, период, приоритет, место доставки, cost center |
| P-03 | **My Requests — List** | Список всех заявок Requestor-а с фильтрами и статусами |
| P-04 | **Request Detail (Requestor view)** | Детальный просмотр поданной заявки: статус, назначенная техника, причина отказа |

### Роль: Fleet Owner

| # | Страница | Описание |
|---|---------|---------|
| P-05 | **Incoming Requests — List (FO view)** | Список заявок, ожидающих решения FO |
| P-06 | **Request Detail (FO view)** | Полная карточка заявки для FO: приоритет, период, тип техники, кнопки Confirm/Reject |
| P-07 | **Assign Equipment** | Выбор конкретных единиц техники для прикрепления к заявке |

### Роль: CC Owner

| # | Страница | Описание |
|---|---------|---------|
| P-08 | **Incoming Requests — List (CC Owner view)** | Список заявок Cat 3, ожидающих согласования CC Owner |
| P-09 | **Request Detail (CC Owner view)** | Карточка заявки с Justification и Cost Center для проверки |

### Роль: Contract Specialist

| # | Страница | Описание |
|---|---------|---------|
| P-10 | **Bid Management** | Список заявок Cat 3, одобренных CC Owner; ввод результатов тендера |
| P-11 | **Enter Bid Results** | Форма ввода анонимных ставок (Bidder 1/2/3: сумма + дата мобилизации) |

### Роль: Administrator

| # | Страница | Описание |
|---|---------|---------|
| P-12 | **Admin Panel — Settings** | Настройка параметров системы: таймеры FO (24h/48h), максимальный срок бронирования |
| P-13 | **Equipment Catalog** | Реестр всей техники: атрибуты, статусы, категории (Cat 1/2/3), тип (Mobile/Stationary) |
| P-14 | **Fleet Management** | Управление парками: назначение FO, состав флота |
| P-15 | **Users & Roles** | Управление пользователями и ролями (интеграция с Azure AAD) |

## Модальные окна

| # | Модал | Триггер | Содержимое |
|---|-------|---------|-----------|
| M-01 | **Tral Notice** | Выбор стационарной техники при создании заявки | Информационный баннер: "A trailer (tral) booking will be automatically added to this request" |
| M-02 | **Submit Request Confirmation** | Кнопка Submit на P-02 | Краткое резюме заявки + кнопки Confirm / Back |
| M-03 | **Request Submitted — Success** | После успешной подачи | Номер заявки, ожидаемый срок ответа FO |
| M-04 | **Withdraw Request** | Кнопка Withdraw на P-04 | Предупреждение: "This action cannot be undone" + Confirm / Cancel |
| M-05 | **FO Reject Request** | Кнопка Reject на P-06 | Textarea причины отказа (обязательное поле — R-33) + Submit |
| M-06 | **FO Confirm — Assign Equipment** | Кнопка Confirm на P-06 | Быстрый выбор единицы техники (сокращённая версия P-07) |
| M-07 | **Justification Required** | Когда внутренняя техника недоступна | Форма: текст обоснования + выбор Cost Center |
| M-08 | **No Equipment Available** | Система не нашла свободной техники Cat 1/2 | Уведомление + предложение: "Search among Business Partners?" |

## Статусы заявок (для бейджей)

| Статус | Цвет (в серой схеме) | Описание |
|--------|---------------------|---------|
| Draft | Светло-серый | Черновик, не подан |
| Submitted | Синий / средне-серый | Подан, ожидает ответа FO |
| Confirmed | Зелёный | Техника назначена |
| Rejected | Красный | Отклонено FO |
| Withdrawn | Тёмно-серый | Отозвано Requestor-ом |
| In Progress | Синий | Техника в работе |
| Completed | Зелёный (приглушённый) | Завершено |
